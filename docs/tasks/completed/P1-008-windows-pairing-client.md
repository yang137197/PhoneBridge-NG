# P1-008 Windows 首次配对与只读连接界面

状态：已完成。P1-007 验收后的限定任务。

## 目标

让 Windows 用户在 NG 客户端中发现手机、输入短码、在手机批准后直接打开只读盘符；将已验证模块接成可操作的首次连接流程。

## 范围

先更新架构，再实现正式 v3 发现模型/解析、真实 TCP PAKE 与严格 HTTPS 配对客户端，复用现有协议和 DPAPI 存储。WPF 最小中英文界面显示设备、输入短码、等待手机批准、连接/打开/卸载/撤销状态；网络/密码学离开 UI 线程。新认证 session 核对后才通过现有 MountManager 创建只读会话，rclone 凭据仅使用已受保护记录，不从临时测试配置或命令行读取。明确实验 v2 与 v3，禁止自动降级/密码迁移。

Pending/取消/回执丢失/离线撤销、关窗/退出与所属 rclone 进程寿命遵循 PAIRING 和现有租约规则。首次连接必须实际验证 Windows → Android NG → rclone → WinFsp → 文件，不能用网络测试宿主代替界面完成。

## 不做什么

不做安全模式写入/删除确认、写缓存、完整自动重连/自启、安装器、发布或 UI 大范围美化。只读必须明确显示为当前开发能力；不改变正式默认安全模式。真机按既有备用机授权和现场连接核对，不扩大共享目录。

## 涉及文件

windows 正式网络配对/发现/界面与必要挂载适配，中英文资源，相应行为/真实链路测试和架构/验收记录。保留现有模块，不重写密码学或文件系统驱动。

## 实现

架构已先记录于根 ARCHITECTURE.md 第 15 节。增加正式 Connection 组合层和 WPF 入口，补足发现 v3 与撤销后本地清理；保持现有密码学、存储保护和只读挂载机制。

## 测试

协议连接/取消/超时、错误 CA/SAN/重定向、无确认零 token 发送、DPAPI Pending-before-POST、迟到激活/待撤销禁止挂载；v2/v3/恶意 TXT 与新发现字段。真实 NG 小文件及已有只读会话的挂载/读取/卸载，界面操作与关窗/退出后进程清理。仅更新实际运行的产品矩阵。

## 验收结果

已完成。最终 locked restore、Release build（0 warnings/0 errors）和 215 项 Windows 测试通过，包括 15 项正式网络组合层行为测试。备用 Redmi K40（Android 16/API 36）通过 WPF 完成 v3 mDNS 发现、短码配对、手机批准、DPAPI 记录、严格 session 核对、rclone/WinFsp 只读挂载、目录及小文件读取、卸载、已保存配对重连与关窗清理。实测发现挂载完成后盘符选择漂移，已修正为挂载期间不刷新可用盘符，并验证 `P:` → 卸载 → `P:`。退出后客户端/rclone 均为 0，盘符消失，手机测试共享已停止且配对记录保留。详见 [验收记录](../../audit/P1-008-VALIDATION.md)。

本任务没有验证安全模式写入/删除确认、自动重连、自启/托盘、网络/睡眠恢复、英文布局、大文件或安装分发，不能宣称整个项目或 MVP 可正式使用。唯一下一任务为 P1-009 安全模式写入与删除保护。

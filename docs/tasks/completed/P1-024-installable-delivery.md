# P1-024 本地可安装交付包

状态：已完成。验收日期：2026-09-22。

## 目标

把已通过真机主链路的开发预览收口为普通用户可安装、可卸载的本地 Windows 包和可侧载 Android APK，为后续完整 MVP 验收提供真实安装形态。

## 范围

Windows 提供一个安装入口，部署固定版本客户端和已核验 rclone，检测 WinFsp；未安装时只引导至已核验的官方安装包或明确停止，不静默下载未知二进制。安装、升级覆盖和卸载必须保留或明确处理当前用户配对记录、缓存和自启动项，不能遗留运行进程或盘符。

Android 生成可重复构建的侧载 Release APK，并明确签名、版本、SHA-256 与最低系统要求。项目只作第三方分发，不加入应用商店、账号、遥测或更新服务器。

先完成本机隔离安装/卸载验证，再用现有 Samsung 做一次安装版配对记录保留、共享、挂载和退出主流程；复用已有文件完整性证据，不重复大文件矩阵。

## 不做什么

不发布 GitHub Release，不上传应用商店，不购买或伪造代码签名证书，不实现自动更新、在线下载器、多设备同时挂载、UI 重设计或新的文件功能。

## 涉及文件

- Windows 发布/安装项目、固定依赖清单及安装验证脚本。
- Android Release 构建与侧载制品说明。
- README、依赖/许可、测试和验收记录。

## 实现

新增固定版本的本地交付脚本和 Inno Setup 安装器。Windows 单一安装入口按当前用户部署自包含 .NET 10.0.12、rclone 1.75.1、许可材料，并检测 WinFsp；缺失时只运行内置且散列、数字签名均已核验的官方 MSI。安装器以应用互斥体拒绝在客户端仍运行时覆盖，不强杀盘符或进程；升级和卸载保留 `%LOCALAPPDATA%\PhoneBridge-NG`，卸载仅清理仍精确指向本次安装路径的自启动值，不移除 WinFsp。

Android 生成 `0.1.0` Release APK，经 zipalign 后使用本机既有测试证书签名，输出证书摘要、SHA-256 和交付 manifest。脚本不下载、不安装、不连接设备、不发布，也不保存签名私钥。依赖、许可、签名边界和操作方法见 [本地交付说明](../../LOCAL_DELIVERY.md)。

## 测试

固定 Windows Release 构建 0 warnings、0 errors，六个项目 279/279；Android Debug/Release、test APK、单元测试和两套 Lint 构建成功，共 123 个 Gradle task。最终交付脚本从锁定工具链完整成功运行。

Windows 实际完成首次安装、运行中升级阻断、退出后覆盖升级、卸载和最终重装。安装版自动连接 Samsung 并约 13 秒挂载 P:；运行中安装器返回失败且保留原客户端、rclone 和盘符。升级前后配对文件散列不变；卸载移除应用、快捷方式和本安装路径的启动项，保留配对/会话、缓存边界与 WinFsp。最终制品再次覆盖安装返回 0，两份配对记录及存储锁文件均未变化，自启动保持用户此前的关闭选择，且无进程或盘符残留。

Samsung 以同证书 `adb install -r` 覆盖安装，版本由 `0.1.0-dev` 变为 `0.1.0`，首次安装时间不变；`LY` 配对、安全模式和 Music 目录保留。共享服务、8273 监听和安装版 Windows 挂载均通过，完成后共享、WakeLock、P:、rclone 和 Windows 客户端均已停止。

## 验收结果

通过限定范围。最终 Windows 安装程序和本地测试 APK 已生成并记录散列；实际安装、升级、运行中阻断、卸载、配对保留及 Samsung 覆盖安装主流程通过。未在无 WinFsp 的机器实际触发管理员安装分支，且两个产物均没有正式产品代码签名，因此只称本地预览，不作公开发行。完整证据见 [P1-024 验收](../../audit/P1-024-VALIDATION.md)。

# P2-013 — v0.2.2 全新机器配对验收

状态：未执行并关闭。日期：2026-09-28。

## 目标

只使用 GitHub `v0.2.2` Release，在真正没有 PhoneBridge NG 的 Windows 11 x64 机器完成首次安装、全新电脑配对和本版本盘符/状态修复验收。

## 范围

- 核对 Release 六项资产和 SHA-256。
- 验收 Windows/WinFsp 首装、Android 正式 APK、全新电脑配对及不自动挂载。
- 按 [全新机器验收清单](../../V0.2.2_CLEAN_MACHINE_ACCEPTANCE.md) 验证设备名/备注、挂载汇总、停止共享、盘符清理、Auto 顺序和配对后固定盘符设置。
- 记录版本、安装日志、盘符占用、必要截图和脱敏诊断证据。

## 不做什么

- 不开发新功能，不使用 r22 或本地候选替代 GitHub Release。
- 不卸载日常机器的 WinFsp 伪造干净环境。
- 不清空数据、重复点击、换盘符或降低断言绕过失败。
- 不重复大文件、睡眠、重启或双手机矩阵。

## 停止条件

测试机并非全新环境、资产摘要不符、安装要求异常重启、配对/身份不唯一、盘符/状态任一断言失败时立即停止并保留现场。

## 验收结果

未执行。用户在全新机器可用前明确转入 `v0.2.3` 有界自动重连开发，因此本任务关闭但不记为通过；`v0.2.2` 的全新机器首次配对、备注卷名和完整盘符矩阵仍是未验证事实。后续正式候选必须以届时最新正式 Release 为升级基线，并在真正全新机器重新覆盖本任务的安装、首次配对和盘符/状态断言，不能引用本文件冒充验收证据。

# P2-002 视觉变量冻结候选

状态：r1，等待用户确认。v0.2.0 只设计浅色主题；本表集中变量，但不增加主题选择器。

## 1. 色彩

| Token | 值 | 用途 |
| --- | --- | --- |
| `color.bg.canvas` | `#F4F7FB` | 窗口/页面背景 |
| `color.bg.surface` | `#FFFFFF` | 卡片、对话框、输入表面 |
| `color.bg.subtle` | `#EDF4FC` | 选中导航、信息区、轻量状态底 |
| `color.text.strong` | `#172033` | 标题、关键数字 |
| `color.text.default` | `#354154` | 正文、控件标签 |
| `color.text.muted` | `#667487` | 辅助说明、时间、次级元数据 |
| `color.border.default` | `#D8E1EC` | 卡片、输入框和分隔线 |
| `color.action.primary` | `#1769E0` | 主按钮、选中态、焦点 |
| `color.action.hover` | `#0E59C7` | 主按钮 hover |
| `color.action.pressed` | `#0B49A5` | 主按钮 pressed |
| `color.connection` | `#109DA8` | 连接/桥接强调；不替代成功色 |
| `color.success` | `#16865B` | 已连接、成功 |
| `color.warning` | `#A85F00` | 需要注意、待确认 |
| `color.danger` | `#C43D4B` | 身份错误、破坏性操作 |
| `color.disabled.bg` | `#E9EEF5` | 禁用控件背景 |
| `color.disabled.text` | `#8A96A6` | 禁用文字 |

状态背景使用对应语义色约 8%–12% 的浅色面；文字和图标仍使用深色语义值。颜色对比度需在实现后以真实字体和控件尺寸复核，本表不声称已通过 WCAG。

## 2. 字体

Windows 字体栈：`Segoe UI, Microsoft YaHei UI, sans-serif`。Android 使用系统 sans-serif 与系统中文字体，不打包新字体。

| 角色 | Windows | Android | 字重/行高 |
| --- | --- | --- | --- |
| 页面标题 | 28 px | 28 sp | 600 / 1.25 |
| 区块标题 | 20 px | 20 sp | 600 / 1.30 |
| 卡片标题 | 16 px | 16 sp | 600 / 1.35 |
| 正文 | 14 px | 14 sp | 400 / 1.50 |
| 控件标签 | 14 px | 14 sp | 600 / 1.25 |
| 辅助文字 | 12 px | 12 sp | 400 / 1.45 |
| 配对码 | 32 px 等宽数字 | 36 sp 等宽数字 | 600 / 1.20，四位分组 |

不使用全大写英文导航，不通过超大标题制造“营销页”观感。

## 3. 间距与布局

- 基础单位：4。
- 间距序列：`4 / 8 / 12 / 16 / 24 / 32 / 48`。
- Windows 页面外边距：32；侧栏宽度：216；卡片内部：24；卡片间距：16。
- Windows 基准窗口：1200 × 760；最小窗口仍沿用现有 820 × 660，在实现任务验证折行和滚动。
- Android 页面水平边距：16 dp；区块间距：24 dp；卡片内部：16 dp；控件间距：12 dp。
- 设备列表使用开放页面加单层卡片，不再给卡片套第二层大容器。

## 4. 圆角、边框与阴影

| 角色 | Windows | Android |
| --- | --- | --- |
| 小控件 | 8 px | 8 dp |
| 按钮 | 8 px | 12 dp |
| 卡片 | 12 px | 16 dp |
| 对话框/步骤容器 | 16 px | 20 dp |

- 默认边框：1 px `color.border.default`。
- 选中/焦点边框：2 px 主色；不得只依赖阴影。
- 卡片阴影仅用于与背景分离：建议 `0 4 16 rgba(29, 52, 84, 0.08)`；若 WPF 阴影影响性能，可保留边框并取消阴影，不改变布局。
- 禁止玻璃拟态、强渐变、霓虹光晕和多层嵌套阴影。

## 5. 按钮层级

1. 每个页面/卡片最多一个实心主按钮。
2. 次按钮为白底边框；低频入口使用文本按钮或菜单。
3. 破坏性按钮不与主按钮并排抢占视觉焦点，放在独立“危险操作”区。
4. `打开文件`是已连接卡片主按钮；`断开`始终为次按钮。
5. `开始共享/停止共享`是 Android 首页唯一实心主按钮。

## 6. 图标

- 风格：圆角线性或轮廓+少量实心，不混用锐角、厚填充和细线。
- 基准网格：24 × 24；标准描边 1.75–2 px，圆端点和圆连接。
- Windows 导航 20–24 px，控件 16–20 px，设备占位 32 px。
- Android 控件 20–24 dp，触控容器不小于 48 dp。
- 托盘必须另作 16 px 单色简化，不直接缩小彩色应用图标。
- 应用图标需保留至少 12.5% 安全区；Android adaptive foreground 不把关键连接结构放到裁切边缘。
- 状态图标必须配文字；托盘状态使用同一轮廓，通过小型附加标记区分离线/连接中/已连接/错误。

## 7. 动效

- 状态过渡：160–200 ms，标准 ease-out。
- 页面切换：200–240 ms，轻微淡入/位移；不得阻塞操作。
- 长任务使用不确定进度环或真实阶段文字，不生成虚构百分比。
- 尊重 Windows/Android 的减少动画设置；静态状态始终可理解。

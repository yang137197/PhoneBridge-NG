# P2-018 验证记录 — v0.2.4 按设备汇总底栏状态

日期：2026-09-28。结果：实现和自动验证通过；尚未形成安装候选或实机界面结论。

## 已确认根因

- 底栏左侧 `Status` 保存当前选中设备最近一次操作消息，稳定状态可能依赖选择并保留历史文案。
- 底栏右侧 `MountSummary` 只保留盘符字符，不携带设备身份或显示名称，所以多设备时无法表达“设备 → 盘符”的对应关系。
- 原汇总对 `Starting`、`RecoveringWrites`、`Stopping` 和 `StopFailed` 的优先级用于保护重要状态，应保留，不能用新文案覆盖。

## 实现

- 汇总输入增加设备 ID、设备显示名称、实际挂载身份、挂载状态和盘符；只有 `Mounted`、身份精确匹配且盘符存在才计为已连接。
- 显示名称直接使用 `PairingRecord.DisplayName`，继续保持 Windows 设备备注优先、手机原始名称兜底，不暴露设备 GUID。
- 稳定状态无挂载时显示“请连接手机。”和“当前无挂载盘符。”。
- 单设备和多设备按盘符稳定排序；左侧合并已连接设备名称，右侧逐项显示“设备挂载在盘符”，不依赖当前选中卡片。
- 挂载中、缓存恢复、安全卸载和卸载失败仍保持原高优先级提示；错误身份即使状态异常标为 `Mounted` 也不会进入连接汇总。
- 简体中文、English 和默认资源同步；Windows 文件版本、产品版本和界面版本前移到 `0.2.4` / `0.2.4.0`。
- 正式交付脚本仍绑定已发布的 `0.2.3`，并增加 Windows 项目版本失败关闭检查；当前开发源码不能被误包装成旧版本。

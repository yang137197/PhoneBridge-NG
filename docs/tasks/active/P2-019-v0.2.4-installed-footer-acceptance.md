# P2-019 — v0.2.4 安装候选与底栏实机验收

状态：待开始。日期：2026-09-28。

## 目标

生成可核验的 v0.2.4 安装候选，以当前正式 GitHub Latest 为动态升级基线，验证真实 Windows 底栏在无挂载、单设备和多设备状态下的设备名称与盘符对应关系。

## 范围

- 开始时重新回读 GitHub Latest；若不再是正式 `v0.2.3`，停止并重定升级基线。
- 统一前移 Windows、Android、安装说明和交付脚本版本，使用既有正式 Android 签名身份生成六项候选并核对摘要。
- 从正式基线原位升级，确认配对、设备备注、访问模式、盘符偏好和已有缓存保持。
- 实机验证无挂载时的两项默认提示、单设备备注/原名与盘符、两台设备合并显示，以及任一设备断开后另一设备仍保持正确。
- 核对挂载中、缓存恢复、安全卸载和卸载失败不会被稳定连接汇总错误覆盖。

## 不做什么

- 不修改连接协议、挂载生命周期、盘符分配或自动重连策略。
- 不重复无关的大文件、睡眠、手机重启或完整功能矩阵。
- 不推送、不打标签、不创建 GitHub Release；正式发布和全新机器验收继续作为独立任务。

## 停止条件

正式基线或资产摘要异常、签名不连续、升级丢失状态、底栏设备与盘符映射错误、错误身份被显示为已连接，或安全状态提示被覆盖时立即停止并保留证据。

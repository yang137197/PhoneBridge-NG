# PhoneBridge NG v0.2.2 全新机器配对验收

用途：在一台没有 PhoneBridge NG 的 Windows 11 x64 机器上，对 GitHub Release `v0.2.2` 做首次安装、全新电脑配对和本版本七项盘符/状态修复验收。此清单不替代已经完成的 `v0.2.0 → v0.2.2` 原位升级门禁。

## 1. 前置条件

- 只从 GitHub Release `v0.2.2` 下载 Windows 安装器、Android APK、`README.txt`、`SHA256SUMS.txt`、源码 ZIP 和 manifest。
- Windows 没有安装 PhoneBridge NG；如需覆盖 WinFsp 首装分支，机器也必须没有 WinFsp。不要为制造“干净”条件卸载日常机器正在使用的驱动。
- 手机与 Windows 在同一局域网；准备一个 USB 盘或一个已占用网络盘符，用于 Auto 冲突验证。
- 不使用 r22 UI 预览、Debug APK 或本地开发输出。

## 2. 制品核对与安装

1. 用 `Get-FileHash -Algorithm SHA256` 核对 Release 的 `SHA256SUMS.txt`，再核对 `delivery-manifest.json` 中的文件名、版本和摘要。
2. 安装 `PhoneBridge-NG-Setup-0.2.2.exe`；记录 WinFsp 是否由安装器触发、UAC 结果和是否要求重启。
3. 安装正式 `PhoneBridge-NG-0.2.2.apk`；确认 Android 显示版本 `0.2.2`。
4. Windows 启动后确认没有自动连接、rclone 或 PhoneBridge 盘符。

## 3. 全新配对与基础连接

1. 手机选择共享目录，进入“配对新电脑”；Windows 点击“添加手机”，使用 8 位码完成新电脑授权。
2. 确认双方各只有一条对应配对记录；Windows 配对完成后仍不自动挂载。
3. 手机开始共享，Windows 点击“连接”；确认出现一个盘符，根目录可读。

## 4. 本版本专项验收

1. **设备名显示**：未设置备注时，Explorer 应显示手机设备名称，不显示随机 GUID。
2. **设备备注显示**：在 Windows“设备设置”保存一个测试备注，断开并重新连接；Explorer 应显示备注。备注不能改变设备身份、访问模式或配对数量。
3. **挂载汇总**：存在盘符时底部不能显示“当前无挂载盘符”；断开后应显示无挂载盘符。
4. **停止共享**：保持 Windows 已连接，只在手机点击“停止共享”；Windows 不得继续显示“手机会话正常”，应转为未连接/离线或重连状态。
5. **盘符清理**：停止共享后盘符、rclone 应消失；Explorer 不应长期残留红叉盘符。
6. **Auto 顺序**：记录测试前所有 C:–Z: 占用；选择 Auto 后应得到 D:–Z: 中首个未被本地磁盘、USB、网络盘或其他 PhoneBridge 会话占用的盘符。
7. **配对后可改盘符**：设备设置必须始终提供 Auto 与固定 D:–Z:。保存固定空闲盘符后，下一次连接使用该盘符；选择已占用盘符时应明确失败，不得静默改用其他盘符。

## 5. 安全断开与证据

- 等待所有复制完成，在 Windows 点击“断开”，确认盘符和 rclone 消失，客户端保持运行。
- 记录 Windows/Android 版本、安装日志、盘符占用前后、Explorer 截图、PhoneBridge 状态截图和必要诊断日志；截图不得包含配对码或用户文件内容。
- 任一断言不符即停止，保留现场和日志；不要通过重装、清数据、重复点击或换盘符绕过。

# P2-015 — v0.2.3 安装候选与有界重连实机验收

状态：待开始。日期：2026-09-28。

## 目标

生成可核验的 v0.2.3 安装候选，以当前正式 v0.2.2 为动态升级基线，在真实 Windows 与已配对手机验证有界自动重连的用户行为和数据安全边界。

## 范围

- 实时回读 GitHub 最新正式 Release，确认升级基线仍为 v0.2.2；若已变化则停止并重定基线。
- 构建与核对 v0.2.3 Windows/Android 候选、版本、签名、对应源码、散列和 manifest，但不创建标签或 GitHub Release。
- 从正式基线原位升级，确认配对、设置和设备级盘符偏好保持。
- 手机主动停止共享：盘符和 rclone 安全退出，自动恢复在 6 次或 2 分钟内终止；手机重新共享后不得自动挂载，必须点击“连接”。
- 短暂网络中断：在预算内恢复同一身份和原盘符；稳定三个健康周期后新故障获得新的恢复预算。
- 核对无候选等待不增加连接次数，耗尽后释放可安全释放的盘符预留；存在待上传状态时不得强制清理。

## 不做什么

- 不发布、推送标签或创建 GitHub Release。
- 不重复无关的大文件、双设备、睡眠、重启或完整盘符矩阵。
- 不用清数据、卸载重装、换测试身份或降低断言绕过失败。

## 停止条件

正式基线或资产摘要异常、签名不连续、升级丢失配对/设置、自动重连超限、主动停止后再次自动挂载、恢复到错误身份/盘符，或安全停止无法确认时立即停止并保留证据。

# P1-042 — 正式 APK迁移与覆盖升级验收

状态：已完成。日期：2026-09-23。

## 目标

在 Samsung SM-S9180/API 36 测试机上从本地测试证书版本迁移到 P1-041 的正式长期签名版本，重新配对并验证盘符链路及同签名覆盖升级。

## 范围

- 记录迁移前版本、签名和安全停止状态。
- 在 Music 下建立专用小型哨兵文件，确认卸载应用不会影响共享目录数据。
- 卸载测试签名 APK，安装正式签名 APK并核对证书。
- 恢复必要系统权限、选择 Music、开始共享并与当前 Windows 客户端重新配对。
- 验证唯一 P:、小文件读取/写入/重命名、锁屏读取和安全卸载。
- 使用同一正式 APK执行一次覆盖安装，确认正式签名升级连续性及配对保留。

## 不做什么

不重复 1/5/10/20 GB、大目录、睡眠或断网矩阵；不修改产品代码，除非出现可复现的正式构建专属缺陷；不发布或上传产物；不操作非专用测试目录。

## 涉及文件

- `.audit/delivery/p1-041-formal/output/PhoneBridge-NG-0.1.0.apk`：待验收正式 APK。
- 本任务记录、验收报告及 `.audit/runs/P1-042` 机器可读证据。

## 实现

- 在 Samsung 测试机 Music 下建立专用哨兵文件，确认卸载本地测试签名 APK不会删除共享目录数据。
- 卸载本地测试签名版本，安装 P1-041 正式签名 APK，恢复通知、存储和电池优化豁免，并重新配对当前 Windows 客户端。
- 完成首次正式链路后安全卸载 P:，停止共享；随后以同一正式 APK执行一次 `adb install -r`。
- 覆盖安装后复用原配对直接重新挂载，最后安全卸载、停止共享并删除专用测试数据和临时手机辅助文件。

## 测试

- 已安装正式 APK版本、APK SHA-256 和证书 SHA-256 与 P1-041 产物一致。
- 首次正式链路完成 P: 小文件读取、新建、重命名和 Android 独立 SHA-256 核对。
- Samsung 在 Dozing/Keyguard 状态下两项文件读取成功，资源唯一。
- `adb install -r` 返回成功，覆盖前后应用数据 inode 相同，Music 选择、配对电脑 `LY` 和测试文件保留。
- 覆盖后无需配对码即可恢复唯一 P:；正式证书和两端哈希再次通过。
- 最终手机应用进程、TCP 8273、Windows 客户端、rclone、P: 和专用测试目录均已清理。

## 验收结果

正式签名版本已在 Samsung SM-S9180/API 36 完成从测试证书迁移、重新配对、锁屏小文件链路和同签名覆盖升级验收。覆盖升级保留配对与设置；当前默认交付目录仍待下一任务提升为正式签名产物。

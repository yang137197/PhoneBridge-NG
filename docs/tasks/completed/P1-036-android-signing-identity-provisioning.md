# P1-036 — Android 长期签名身份初始化工具

状态：已完成。日期：2026-09-23。

## 目标

为正式长期 Android 私钥提供一次性、失败关闭的初始化入口：在项目目录外生成主 keystore，同步写入用户指定的独立备份目录，核对两份散列与证书身份，并输出不含秘密的身份记录。

## 范围

新增 PowerShell 初始化脚本，固定 PKCS12、RSA-4096、产品别名/证书主题和长期有效期；密码仅从当前进程环境读取。主目录使用当前用户与 SYSTEM 私有 ACL，备份介质保持加密 keystore，不在项目内写入私钥。

## 不做什么

不生成正式长期私钥，不替用户选择外接硬盘/U 盘/NAS，不保存或打印密码，不覆盖已有密钥，不发布 APK，不修改产品运行代码。

## 涉及文件

- `scripts/Initialize-AndroidReleaseSigning.ps1`：一次性密钥初始化和双份核验。
- `docs/LOCAL_DELIVERY.md`、`DECISIONS.md`：操作边界。
- 本任务、验收记录和机器可读证据。

## 实现

- 新增 `Initialize-AndroidReleaseSigning.ps1`，固定 PKCS12、RSA-4096、SHA256withRSA、`phonebridge-release` 别名和产品证书主题。
- 主 keystore 和备份目录必须是项目外的绝对路径，且两目录不能相互包含；任何已有目标文件均拒绝覆盖。
- 密码只读取当前进程环境变量；要求至少 16 个非控制字符，并按 PKCS12 兼容边界要求两值完全相同。
- 生成后核对主副 keystore SHA-256、主副证书 SHA-256，并写入两份完全相同且不含秘密的身份 JSON。
- 主目录、主 keystore 和主身份记录只授权当前用户与 SYSTEM。备份介质可能不支持 ACL，不强行修改其权限。
- 备份文件先提交，主文件后提交；异常时只清理临时文件，保留已提交文件，避免自动删除可能唯一的私钥。

## 测试

- PowerShell 语法解析通过。
- 主路径位于项目内、备份位于项目内、目录嵌套、弱密码、密码不同、已有目标和成功后重跑七项负向用例均以退出码 1 失败关闭。
- 使用系统临时目录下两个独立路径生成一次性身份：主副 keystore 散列一致、身份 JSON一致、证书摘要一致、RSA 位数和别名正确。
- 主目录与主文件 ACL 均为禁止继承，只包含当前用户和 SYSTEM；日志及身份记录未检出随机测试密码或密码环境变量名称。
- 测试根目录和一次性私钥已删除；项目内长期发行密钥为 0。项目保留的 `.audit/android-user/debug.keystore` 仅用于 `LocalTest`。

## 验收结果

通过限定验收。正式长期身份尚未生成；需要用户先指定真正独立的备份介质目录。脚本验证的是路径独立，无法验证两条路径是否位于不同物理介质。

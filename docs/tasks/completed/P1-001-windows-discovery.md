# P1-001 Windows 工程与设备发现

- 状态：已完成限定任务；2026-09-19
- 目标：建立可构建的 C#/.NET LTS Windows 工程与设备发现模型，能从真实 LAN 发现实验手机，并正确处理更新、移除和手动端点。
- 范围：先核对官方稳定 LTS SDK、mDNS .NET 库的维护/许可证/Windows 支持并锁定依赖；以设备模型和可测试发现服务为核心，提供最小诊断入口。需要界面时只做中文资源化的基础列表，不进行视觉重设计。
- 不做什么：不自动挂载、不收集或保存 Basic 密码、不接受 mDNS 的 CA/指纹作为信任、不跳过 TLS、不发布、不制作安装包，不把诊断入口当正式配对功能。
- 涉及文件：windows 工程/构建配置、发现与设备模型、针对行为的测试、README/架构/决策及任务证据。

## 实现

前提为 [Phase 0 门槛](../../audit/PHASE-0-ACCEPTANCE.md)。采用既定 C# + 当前稳定 LTS .NET + WPF 方向；工程建立时重新核实 SDK/补丁版本，本机有运行时不等于有 SDK。上游 Python 仅作行为参考，不复制其 HTTP 容错、发现即信任或 IP 更新缺口。

发现信息全部视为不可信候选：校验端口、协议、地址和字段长度；区分服务实例/当前端点与配对身份，合并与撤销不得按设备名称误认同一可信设备。网络接口变化、重复通知、移除和停止清理有明确语义。手动添加端点与发现路径共用候选模型，不能绕过后续身份验证。

## 测试

编译与相关测试通过；覆盖畸形/超长 TXT、HTTP 候选拒绝、端点更新、移除、重复事件和停止释放。使用既有授权备用机验证真实服务出现/消失，记录接口与时限；测试手机启动仍可使用已验证前台宿主，结束后停止共享。无需重复安装 APK或生成测试文件，保留 P0-010 样本。

## 验收结果

已完成 C#/.NET 10 工程、候选校验、系统 DNS-SD 枚举/更新/撤销、手动 IP 与中英文诊断入口。41 项测试和 4 项 CLI 检查通过；真机最终复测 3.890 秒发现，跨扫描期间不闪烁，停止共享后 35.937 秒移除。`scripts/Verify-Windows.ps1` 与真实设备脚本均 exit 0。原生 watcher 漏掉移除的失败与周期重枚举修复分别保存，详见 [验收报告](../../audit/P1-001-VALIDATION.md)。未验证真实网络切换、三星和长期运行，正式配对与长期凭据仍由 D-03 约束。唯一下一任务为 P1-002 只读挂载生命周期。

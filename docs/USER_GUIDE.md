# PhoneBridge NG 使用说明

本说明适用于正式版 `v0.2.0`。安装文件请从 [GitHub Release v0.2.0](https://github.com/yang137197/PhoneBridge-NG/releases/tag/v0.2.0) 下载。

## 使用条件

- Windows 11 x64。
- Android 8.0（API 26）或更高版本。
- 手机与电脑连接同一局域网。
- Android 端采用侧载安装；Windows 安装器当前没有商业代码签名。

## 安装

1. 在 Release 的 Assets 中下载 Windows 安装器、Android APK 和 `SHA256SUMS.txt`。
2. 在 Android 手机上允许当前文件来源安装应用，然后安装 APK。
3. 在电脑上运行 `PhoneBridge-NG-Setup-0.2.0.exe`。
4. 如果电脑尚未安装 WinFsp，安装程序会启动内置的官方 WinFsp 安装包；确认 Windows 管理员提示后完成安装。

建议安装前使用 PowerShell 核对 SHA-256：

```powershell
Get-FileHash .\PhoneBridge-NG-Setup-0.2.0.exe -Algorithm SHA256
Get-FileHash .\*.apk -Algorithm SHA256
```

计算结果应与同一 Release 中的 `SHA256SUMS.txt` 一致。

## 首次配对

1. 打开手机上的 PhoneBridge NG，选择要共享的目录并授予所需权限。
2. 点击“配对新电脑”，保持配对页面在前台，记下显示的 8 位配对码。此时无需先开始共享。
3. 打开 Windows PhoneBridge NG，点击“添加手机”，选择发现的手机并输入配对码。
4. 手机上出现电脑名称后，确认是当前电脑并点击“允许配对”。
5. 配对完成后，在手机首页点击“开始共享”。如需锁屏传输，按系统提示允许 PhoneBridge NG 忽略电池优化。
6. Windows 设备卡片显示手机可用后，点击“连接”；连接成功后点击“打开文件”。

配对码只用于本次配对，请勿发送给他人。无法确认电脑身份时不要允许配对。

## 日常使用

1. 在手机上打开 PhoneBridge NG，确认共享目录后点击“开始共享”。
2. 在 Windows 客户端找到对应设备，点击“连接”。
3. 连接后点击“打开文件”，在文件资源管理器中使用分配给该手机的盘符。

一台电脑可以同时连接多台已经配对的手机；每台手机使用独立设备卡片和盘符。Windows 登录时自动运行只会将客户端放入系统托盘，不会自动连接手机或挂载盘符。

## 访问模式

每台电脑的访问模式在手机端分别设置：

- 只读：仅浏览和下载，不允许写入或删除。
- 安全模式：允许新建文件，不允许直接覆盖已有文件；删除需要逐项确认。推荐日常使用。
- 完全读写：允许覆盖和删除文件，仅在信任当前电脑且确有需要时使用。

切换访问模式后，应先在 Windows 断开该设备，再重新连接，使新设置生效。

## 设备设置

- 两端的“设备备注”只保存在各自本地，不会同步到另一端。
- 在任一端移除设备只删除该端保存的配对记录；需要重新使用时应重新配对。
- 应用语言可在设置中选择中文或 English，并在重启后保持。

## 正确断开和退出

1. 等待正在复制或写入的文件完成。
2. 在 Windows 对应设备卡片点击“断开”。
3. 如果提示仍有文件等待上传，保持手机共享和网络可用，等待完成后重试。
4. Windows 断开完成后，再在手机上点击“停止共享”。
5. 如需完全退出 Windows 客户端，在系统托盘菜单中选择“退出”。

不要在文件仍在写入时强制结束客户端或停止手机共享。

## 连接失败

按以下顺序检查：

1. 手机仍显示“正在共享”，且手机和电脑处于同一局域网。
2. Windows 客户端点击“刷新”，然后重试对应设备卡片。
3. 已经完成配对但自动发现不可用时，可在“设置 → 高级排障”输入手机当前局域网地址。手动地址不会绕过设备身份验证。
4. 仍无法连接时，在“设置 → 高级排障”导出诊断包。诊断包只保存到用户选择的位置，不会自动上传。

## 升级

从下一个正式版开始，Windows 和 Android 均应直接从当前正式版原位升级，不需要先卸载。升级前先结束文件传输并正常断开；升级后核对版本、原有配对、设置和基础连接是否保留。正式升级来源以 GitHub Releases 中紧邻的前一个正式版本为准。

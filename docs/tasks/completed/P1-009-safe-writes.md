# P1-009 安全模式写入与删除保护

状态：已完成。P1-008 验收后的限定任务。

## 目标

在服务端强制的默认安全模式下支持上传、新建目录和重命名；删除必须经过明确、限时、不可重放的确认，并以可丢弃真机数据证明提交后内容正确。

## 范围

先更新架构和权限/提交契约，再实现 Android WebDAV 写入边界、Windows 模式传递与最小确认界面。复用现有配对身份、严格 TLS、MountManager 和 rclone，不通过命令行或配置泄露长期凭据。

## 不做什么

不做自动重连、托盘/自启、安装器、发布、回收站自动清理、大文件全矩阵或 UI 美化。不触碰非测试目录和个人文件。

## 涉及文件

Android 文件服务与权限状态、Windows Connection/WPF/挂载配置、中英文资源、协议/安全/测试文档及对应自动化和真机证据。

## 实现

ARCHITECTURE 第 16 节、ADR-020/021、PROTOCOL 第 5 节和 SECURITY 第 3 节记录服务端授权、原子提交、覆盖、一次性删除确认、每设备 VFS 写缓存及安全卸载边界。Android 实现 PUT/MKCOL/COPY/MOVE 的服务端模式检查和原子提交，以及 30 秒一次性删除事务；Windows 按模式配置 rclone，并只在显式客户端确认后调用删除控制 API。SAFE/READ_WRITE 使用稳定的每设备 `writes` 缓存，卸载前核对受认证 RC 状态。

## 测试

覆盖未确认、过期、变化和重放删除拒绝，上传中断不替换旧文件，目录/文件重命名边界，COPY/MOVE 不绕过策略，写缓存参数、缓存隔离、待上传保护与卸载状态解析。备用 Redmi K40 的可丢弃 Music 测试数据通过 Explorer 上传、新建、重命名、过期删除拒绝、重新确认删除和安全卸载。

## 验收结果

已完成限定验收。Windows Release 构建 0 warnings/0 errors，218 项测试通过；Android Debug/Release/test APK、单元测试和双配置 Lint 共 123 个 Gradle task 成功。真机 45 个仪器测试用例均已分别通过，但因手机息屏没有取得一次不中断的 45/45 单次运行。

真机保存配对可恢复严格会话并挂载 `P:` 安全模式；Explorer 创建并重命名目录、创建 7 字节文件并写回手机。首次删除确认超过 30 秒后服务端拒绝且目标保留；刷新确认后文件和目录删除成功，ADB 独立回读均不存在。卸载后 `P:`、rclone、桌面进程和 Android 共享服务均不存在，稳定缓存目录保留。详见[验收记录](../../audit/P1-009-VALIDATION.md)。

未验证 100 MB 以上写入、已有目标覆盖的 Explorer 行为、断网/磁盘满/异常退出后的真实缓存恢复、三星设备、自动重连和完整 MVP。Android 已保存配对列表在部分进程/测试生命周期后可能不刷新，但本次 Windows 保存记录仍可认证连接。后续任务 [P1-010 断线卸载与自动重连](P1-010-auto-reconnect.md)现已完成。

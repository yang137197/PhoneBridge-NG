# P2-001 — v0.2.0 需求与开发计划

状态：已完成。日期：2026-09-24。

## 目标

在不修改业务代码的前提下，记录下一版本的两端 UI、图标、语言设置、Windows 操作精简和多设备需求，并给出可逐项验收的开发计划与预期效果。

## 范围

- 明确用户、核心场景、非目标和正式交付物。
- 核对当前 UI、本地化资源和单活动挂载架构。
- 记录推荐的信息架构、按钮归位、图标方向、多设备边界和开发顺序。
- 更新产品需求和 README 当前状态。

## 不做什么

- 不修改 Windows 或 Android 业务代码、资源和构建配置。
- 不制作线框图、视觉稿或图标资产。
- 不开始多设备会话重构，不运行真机或回归测试。
- 不修改既定传输、配对、安全、签名或发布技术路线。

## 涉及文件

- `docs/V0.2_PLAN.md`：完整需求、建议、预期效果和顺序。
- `docs/PRODUCT.md`：v0.2.0 可追踪需求与可观察效果。
- `README.md`：当前状态和计划入口。
- 本记录：本轮边界与结果。

## 实现

确认现有能力可以复用；Windows 多设备需要把单个 `ConnectionClient`/`MountManager` 改为按设备隔离的会话所有权。UI 推荐采用统一现代浅色主题、设备卡片和按状态出现的主操作；危险与排障操作移入对应设置。两端首次默认简体中文，并提供持久 English 设置。

## 测试

本轮只做文档一致性检查。没有运行构建、自动化测试或真机验收，因为没有修改可执行代码。

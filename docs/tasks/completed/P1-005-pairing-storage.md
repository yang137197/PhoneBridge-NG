# P1-005 Windows 受保护配对记录

- 状态：已完成限定任务；产品配对尚未完成。
- 目标：落实 ADR-017 的当前用户 DPAPI 配对记录，使首次配对在发送长期 token 前能够持久保存 Pending，重启后可安全回读。
- 范围：单条身份/CA/token/状态的严格模型、CA 解析与自签名校验、DPAPI UI_FORBIDDEN、当前用户/SYSTEM 私有 ACL、有限长度/原子写入、恢复与禁用状态、破损/错误用户失败关闭；提供后续配对及挂载可调用的单一存储路径。
- 不做什么：不连接手机，不实现 HTTP 授权/Keystore/Android UI、自动挂载或大规模重构；不导入实验明文密码，不发布安装包。
- 涉及文件：ARCHITECTURE、Windows 配对/凭据存储模块、Windows 行为与本机 DPAPI/文件系统测试、依赖/审计与任务记录。

## 实现

先复核 [PAIRING](../../PAIRING.md) 第 6、7 节和 P1-002 的信任文件策略；固定记录格式与失败状态，再实施原子受保护写入。临时文件只能是密文；记录中的 CA SHA、device_id、client_id、token 与状态共同保护。现有身份冲突不覆盖，文件丢失/损坏不能自动创建宽松信任。

## 测试

实际 CurrentUser DPAPI 往返、材料篡改/错误绑定/错误状态/超长、写入失败与各提交边界、目录/文件 ACL 与 reparse 路径、同机并发、重开恢复和未完成 Pending 不可挂载。错误用户无法解密若不能安全模拟或以授权的真实用户环境验证，明确记录边界；不为测试修改本机账号或策略。检查日志、普通配置、命令行和测试产物不含实际秘密。

## 验收结果

限定验收通过。新增 PhoneBridge.Credentials 与两个测试工程，实际 CurrentUser DPAPI、私有 ACL、CA 自签名、状态/修订号、原子密文提交及恢复完成。复核补强原生内存释放、输入预检、Active 模式刷新、测试子进程退出及已复现文件占用的有界重试。

正式 Verify-Windows 脚本退出 0，Release 构建 0 警告/0 错误，184 项 Windows 测试通过（41 发现、33 挂载/进程、50 配对、60 存储），0 失败/0 跳过。匿名 impersonation 解密拒绝已在独立子进程验证，不等同第二个正常登录用户。首轮测试声明错误、并行回归占用失败、诊断与修复分别保留，详见 [P1-005 验收](../../audit/P1-005-VALIDATION.md)。

未接网络/手机，未改实验 APK。断电、第二个正常用户、Android Keystore 配对集、完整授权/撤销/UI/自动重连尚未验证；不声称 MVP 或日常可用。

# PhoneBridge NG v0.2.3 全新机器配对验收

用途：在一台没有 PhoneBridge NG 的 Windows 11 x64 机器上，对 GitHub Release `v0.2.3` 做首次安装、全新电脑配对、盘符/状态和有界自动重连验收。此清单不替代已经完成的 `v0.2.2 → v0.2.3` 原位升级门禁。

状态：关联的 P2-017 未执行并关闭；本清单仅保留为历史范围，不是当前验收入口。

## 1. 前置条件

- 只从 GitHub Release `v0.2.3` 下载 Windows 安装器、Android APK、`README.txt`、`SHA256SUMS.txt`、源码 ZIP 和 manifest。
- Windows 没有安装 PhoneBridge NG；如需覆盖 WinFsp 首装分支，机器也必须没有 WinFsp。不要为制造“干净”条件卸载日常机器正在使用的驱动。
- 手机与 Windows 在同一局域网；准备一个 USB 盘或一个已占用网络盘符，用于 Auto 冲突验证。
- 不清除手机现有数据或配对；本任务验证的是一台全新 Windows 电脑成为新的已配对电脑。
- 不使用 UI 预览、Debug APK、本地候选或 `.audit` 目录中的制品。

## 2. 制品核对与安装

1. 用 `Get-FileHash -Algorithm SHA256` 核对 Release 的 `SHA256SUMS.txt`，再核对 `delivery-manifest.json` 中的文件名、版本和摘要。
2. 安装 `PhoneBridge-NG-Setup-0.2.3.exe`；记录 WinFsp 是否由安装器触发、UAC 结果和是否要求重启。
3. 在手机安装正式 `PhoneBridge-NG-0.2.3.apk`；确认 Android 显示版本 `0.2.3`，不得清除已有应用数据。
4. Windows 首次启动后确认没有自动连接、rclone 或 PhoneBridge 盘符。
5. 记录测试前 C:–Z: 的实际占用，特别标明 USB 盘和网络盘。

## 3. 全新配对与基础连接

1. 手机进入“配对新电脑”；Windows 点击“添加手机”，使用本次新生成的 8 位码完成授权。
2. 确认双方各新增且只有一条对应记录；Windows 配对完成后仍不自动挂载。
3. 手机开始共享，Windows 点击“连接”；确认只出现一个 PhoneBridge 盘符，根目录可读。

## 4. 盘符与状态专项验收

1. **设备名显示**：未设置备注时，Explorer 应显示手机设备名称，不显示随机 GUID。
2. **设备备注显示**：在 Windows“设备设置”保存测试备注，断开并重新连接；Explorer 应显示备注。备注不能改变设备身份、访问模式或配对数量。
3. **挂载汇总**：存在盘符时底部不能显示“当前无挂载盘符”；断开后应显示无挂载盘符。
4. **停止共享状态**：保持 Windows 已连接，只在手机点击“停止共享”；Windows 不得继续显示“手机会话正常”。
5. **盘符清理**：停止共享后盘符和 rclone 应退出；Explorer 不应长期残留红叉盘符。
6. **Auto 顺序**：选择 Auto 后应得到 D:–Z: 中首个未被本地磁盘、USB、网络盘或其他 PhoneBridge 会话占用的盘符。
7. **配对后可改盘符**：设备设置必须始终提供 Auto 与固定 D:–Z:。保存固定空闲盘符后，下一次连接使用该盘符；选择已占用盘符时应明确失败，不得静默改用其他盘符。

## 5. 有界自动重连验收

1. 恢复 Auto，手动连接并确认根目录可读；记录当前盘符和设备身份。
2. 临时断开手机 Wi-Fi，等待 Windows 确认连接丢失后在 2 分钟内恢复同一网络；应在预算内自动恢复同一设备和原盘符，不得产生第二个盘符或 rclone。
3. 恢复后等待连续三个健康周期，再确认文件根目录仍可读。
4. 在手机明确点击“停止共享”；盘符和 rclone 应退出。无端点等待不得持续实际连接尝试，并应在 2 分钟上限后停止恢复。
5. 手机重新开始共享后等待至少 15 秒；Windows 可以重新发现设备，但不得自动挂载。用户点击“连接”后应正常恢复一个盘符。

## 6. 安全断开与证据

- 等待所有复制完成，在 Windows 点击“断开”，确认盘符和 rclone 消失，客户端保持运行。
- 记录 Windows/Android 版本、安装日志、盘符占用前后、Explorer 截图、PhoneBridge 状态截图和必要诊断日志；截图不得包含配对码或用户文件内容。
- 验收记录必须区分首次安装、首次配对、备注卷名、Auto/固定盘符、停止共享和自动重连各项结果。
- 任一断言不符即停止，保留现场和日志；不要通过重装、清数据、重复点击、换盘符或放宽时间上限绕过。

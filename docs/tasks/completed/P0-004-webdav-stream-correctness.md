# P0-004 WebDAV 数据流正确性最小修复

- 状态：已完成本次最小修复与限定验证（2026-09-19）；不代表 Phase 0 或产品完成
- 目标：消除 P0-003 确认的 Range 内容错误和 PROPFIND 后连接失步，恢复非重复 100 MB 数据的完整读写验证。
- 范围：独立于未修改上游的 Android 修复版；GET 单 Range/206/416；有限、完整的请求正文处理/必要时关闭连接；相关回归和挂载复验。
- 不做什么：不开始 WPF、大规模 Android 重写或新 UI，不连接主手机，不把这次修复当配对/安全模式完成。
- 涉及文件：Android 修复版及测试、必要的完整 GPL 文本与来源说明、实验脚本、P0-004 验收文档。

## 实现

已保留 P0-003 原始基线，在独立 `.audit/p0-004-worktree` 修改；最终以可审阅补丁归档到 android/patches，不把整个上游实验 UI/Tailscale 等功能导入 NG 产品。已补齐完整 GPL 文本并保留原许可证/来源说明。保持 WebDAV、rclone、WinFsp 架构。

实现单区间、开放/后缀区间和 206/416；用同一个文件句柄确定长度与偏移，禁用该文件响应的透明 gzip。未实现多区间与强 If-Range 验证，按完整 200 响应处理。

非 PUT 正文限制 1 MiB、精确消费声明长度、设置读取预算；无效/溢出长度、不支持的 Transfer-Encoding 拒绝并关闭连接。认证失败及错误路径关闭连接，避免未读正文成为下一请求。PUT 仅增加 framing 前置检查，原有原子覆盖/短上传风险不在此补丁中解决。

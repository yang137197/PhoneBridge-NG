# P2-018 — v0.2.4 按设备汇总底栏状态

状态：已完成。日期：2026-09-28。

## 目标

让 Windows 底栏的连接状态与挂载汇总来自同一组已验证设备会话，明确显示设备名称和对应盘符，不再依赖当前选中设备或只显示盘符字母。

## 已完成

- 无设备实际挂载时，稳定态显示“请连接手机。”和“当前无挂载盘符。”。
- 单设备和多设备汇总携带设备 ID、备注优先显示名称、实际挂载身份与盘符，并按盘符稳定排序。
- 只有挂载状态、设备身份和盘符三者一致才显示已连接；发现、预留盘符和错误身份不会进入汇总。
- 保留挂载中、缓存恢复、安全卸载和卸载失败的原有高优先级提示。
- 同步简体中文、English 和默认资源；Windows 版本前移到 `0.2.4`，旧正式交付脚本对版本不匹配失败关闭。

## 验收结果

实现和自动验证通过：Windows Release 构建 0 warnings / 0 errors，310/310 测试通过，EXE 版本为 `0.2.4.0`。尚未生成安装候选或取得真实单/多设备界面证据，不发布、不推送。

# PhoneBridge NG v0.2.4 全新机器配对验收

用途：在一台没有 PhoneBridge NG 的 Windows 11 x64 机器上，只使用 GitHub Release `v0.2.4`，验证首次安装、全新电脑配对和关键连接生命周期。状态：待执行；不能用现有机器或原位升级结果代替。

## 1. 制品与环境门禁

1. 只从 <https://github.com/yang137197/PhoneBridge-NG/releases/tag/v0.2.4> 下载六项公开资产；确认 Release 为非草稿、非预发布和 Latest。
2. 用 `SHA256SUMS.txt` 和 `delivery-manifest.json` 核对安装器、APK、README 和源码 ZIP；任一文件名、大小或摘要不一致即停止。
3. Windows 11 x64 机器上不得已有 PhoneBridge NG；如同时验证 WinFsp 首装，机器也不得已有 WinFsp。记录测试前 D:–Z: 占用，并准备一个 USB 或网络盘制造盘符冲突。
4. 手机与 Windows 在同一局域网；不清除手机已有数据或配对。本任务新增一条独立 Windows 电脑身份。

## 2. 首次安装与全新配对

1. 安装 `PhoneBridge-NG-Setup-0.2.4.exe`，记录 UAC、WinFsp 安装和是否要求重启；首次启动后不得自动连接、启动 rclone 或产生 PhoneBridge 盘符。
2. 如手机尚非 v0.2.4，安装公开 `PhoneBridge-NG-0.2.4.apk`；确认系统安装确认和应用版本，不清除应用数据。
3. 手机进入“配对新电脑”，Windows 点击“添加手机”，使用本次新生成的 8 位码完成授权。确认双方各新增且只有一条对应记录，配对后仍不自动挂载。

## 3. 发现、连接与显示

1. 手机未开始共享时，设备卡显示“未查找到设备，请检查手机打开共享”，且不显示活动 IP。
2. 手机开始共享后，Windows 应显示“已查找到设备，可连接”和设备 IP；点击连接后继续显示活动 IP。
3. 连接后只出现一个 PhoneBridge 固定磁盘；Explorer 名称为“设备备注或设备名 (盘符)”，不含 `\\pbng-*`；容量、可用量和使用进度与手机共享存储一致，根目录可读。
4. 底栏无连接时显示“请连接手机”和“当前无挂载盘符”；连接后按设备名显示“已连接”和对应盘符。点击刷新应给出明确成功、找到设备或未找到设备结果。

## 4. 盘符与生命周期

1. Auto 应选择 D:–Z: 中首个未被本地磁盘、USB、网络盘或其他 PhoneBridge 会话占用的盘符。
2. 设备设置应允许在 Auto 与固定 D:–Z: 间修改；固定盘符已占用时必须明确失败，不得静默换盘。
3. Windows 只点击一次“断开”应立即生效；盘符和 rclone 消失，手机共享可以继续，设备卡回到已发现可连接状态。
4. 再次连接后只在手机点击“停止共享”；Windows 不得继续显示已连接或会话正常，盘符和 rclone 应退出，不得长期保留红叉盘符。
5. 短时 Wi-Fi 中断可在既定预算内恢复原设备和原盘符；手机明确停止共享后不得无限重连，重新开始共享也不得自动挂载。

## 5. 更新检查与收尾

1. Windows 左下角显示当前版本 `0.2.4`；手动检查更新应显示“当前已是最新版”，不得后台下载或重复安装。
2. Android 设置页手动检查更新也应显示当前已是最新版；共享期间不得直接进入 APK 更新安装。
3. 等待文件操作完成后安全断开并退出两端；确认无 PhoneBridge 盘符、无 rclone、Windows 客户端退出，Android 无前台共享服务和 8273 监听。
4. 记录安装日志、版本、盘符占用前后、关键界面和必要诊断日志；不得记录配对码、秘密或用户文件内容。

任一断言不符即停止并保留现场；不要通过清数据、重装、重复点击、刷新 Explorer、改盘符或放宽时间上限绕过。

# P1-025 MVP 证据映射与常用目录验收

状态：已完成。验收日期：2026-09-22。

## 目标

把 P1-001 至 P1-024 已取得的真实证据逐项映射到 MVP-01–15，避免重复测试；使用当前安装版和 Samsung 只补齐 DCIM、Download、Pictures 三个常用目录的实际浏览证据，得到准确的剩余 MVP 缺口。

## 范围

逐项核对现有验收报告是否满足对应 MVP 的完整条件，只在证据范围完全匹配时更新 `docs/PRODUCT.md`。通过 ADB 自动切换已授权测试手机的共享目录，使用已安装 Windows 客户端逐个挂载并读取 DCIM、Download、Pictures；每个目录一次即可。若发现真实缺陷，先复现和定根因，再作最小修复。

## 不做什么

不重复 100 MB/1/5/10/20 GB、视频、文件名、三模式或 Wi-Fi 中断测试；不在本任务重启手机/电脑、让 PC 睡眠、制造传输中断、生成 5,000/10,000 个文件、开发多设备并发、持久盘符或新功能。证据不足的条目保持未通过并列为后续最小任务。

## 涉及文件

- `docs/PRODUCT.md` 与 `docs/TESTING.md` 的证据状态。
- P1-001 至 P1-024 验收记录和本任务审计摘要。
- 仅在实测发现缺陷时涉及对应 Android/Windows 代码。

## 实现

逐项回读 P0-010、P1-001 至 P1-024 验收的触发条件、设备、路径和独立结果，只在证据覆盖完整标准时更新 MVP 表。没有用窄单元测试代替真机要求，也没有重复大文件或故障矩阵。

Samsung 使用最终 `0.1.0` APK和当前安装版 Windows 客户端，ADB 自动选择 DCIM、Pictures、Download 并开始共享；每次前一盘符消失后再启动下一目录。Windows 读取 P: 顶层名称，与 Android 独立目录列表作数量和名称集合比对。

## 测试

DCIM 为 3/3 项全部对应、首次安装版挂载 6.352 秒；Pictures 为 19/19、挂载 2.017 秒；Download 为 5/5、挂载 2.024 秒。每轮只有一个桌面客户端和一个 rclone。未改产品代码，因此不重跑已通过的 279 项 Windows 和 123 个 Android task；这些最近完整回归来自 P1-024。

## 验收结果

通过。MVP-01、02、05–12 共 10 项已有完整证据；MVP-03 仍为部分通过，MVP-04、13、14、15 尚未完成。最终共享目录恢复为 Music，共享停止，Android 前台服务、8273、WakeLock、P:、rclone 和 Windows 客户端均不存在。完整证据见 [P1-025 验收](../../audit/P1-025-VALIDATION.md)。

# P2-029 — Windows 与 Android 首次使用引导

状态：已完成。日期：2026-09-30。

## 目标

在真正的全新安装首次使用时，向用户说明同一局域网、手机配对、Windows 输入配对码、手机批准、开始共享及 Windows 连接盘符的完整顺序；两端同时提供可再次打开的“使用帮助”入口。

## 范围

- Windows 在尚未完成引导且没有任何既有配对记录时显示首次使用页；“稍后”和“开始添加手机”均结束本轮首次提示。
- Windows 已有配对记录的升级用户不弹首次引导，并将其视为已完成迁移。
- Windows“关于”页提供“使用帮助”入口。
- Android 等待已配对电脑记录加载完成后再判断首次使用；尚未完成引导且没有既有配对电脑时显示引导。
- Android 已有配对电脑的升级用户不弹首次引导，并将其视为已完成迁移。
- Android“设置”页提供“使用帮助”入口。
- 两端提供简体中文和 English 文案，并补充状态判定自动测试。
- 更新仓库用户指南，使下载文件名与版本描述不再固定为旧版 v0.2.0。

## 不做什么

- 不修改配对协议、发现、共享、挂载、凭据或更新安全策略。
- 不自动申请权限、自动开始共享、自动配对或自动连接盘符。
- 不实现多页强制向导、动画、遥测或后台提示。
- 不安装候选、不推送、不打标签、不创建 GitHub Release。

## 涉及文件

- Windows 首次引导状态、主窗口、双语资源及 Desktop 测试。
- Android 首次引导策略、主界面、共享服务加载状态、双语资源及 JVM 测试。
- `docs/USER_GUIDE.md`
- `README.md`
- `docs/HANDOFF_V0.2.md`

## 实现

- Windows 新增独立首次引导完成标记。无标记且无配对记录时自动显示引导；已有配对记录的升级用户静默写入迁移标记，不显示首次引导；配对存储不可用或 UI 预览模式不自动显示。
- Windows 引导按“同一局域网与打开两端 → 手机显示配对码 → Windows 输入并由手机批准 → 手机共享与 Windows 连接盘符”说明主流程；返回、“稍后”和“开始添加手机”具有明确去向。“关于”页可再次打开“使用帮助”。
- Android 新增同等引导和“设置 → 使用帮助”入口。首次判定会等待共享服务异步加载完已有配对记录，避免在升级用户的记录尚未加载时误判为全新安装；配对存储异常时不覆盖故障状态。
- Android 测试桥接入口显式写入已完成标记，避免自动化测试被首次引导遮挡；生产路径不受该测试设置影响。
- 两端均使用简体中文/English 资源；没有自动申请权限、自动开始共享、自动配对或自动连接。
- 用户指南改为指向 Latest 正式版本和版本无关的安装文件名，补充两端内置帮助入口，并移除已经过时的 Android 更新“尚未真机验收”表述。

## 验收结果

代码与自动验证范围通过。两端都会只对“无完成标记且无已有配对”的首次使用显示主流程引导，并提供永久帮助入口；已有配对的升级用户不会因缺少新标记而被误弹。真实安装版首次显示、双端视觉和升级迁移仍须在后续正式候选验收中验证，不能由构建或单元测试代替。

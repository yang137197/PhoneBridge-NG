# P2-021 — v0.2.4 全新机器配对验收

状态：未通过并关闭。日期：2026-09-29。

## 目标

在一台没有 PhoneBridge NG 的 Windows 11 x64 机器上，只使用 GitHub Release `v0.2.4` 的公开资产，验证首次安装、全新电脑配对和关键连接生命周期。

## 范围

- 下载并核对公开安装器、APK、README、SHA256SUMS、对应源码和 manifest，不使用本地候选。
- 验证无旧客户端条件下的首次安装、启动和全新电脑配对，确认配对完成后不自动挂载。
- 验证发现/IP 提示、手动连接、简洁设备卷名、真实容量、文件访问、Auto 与固定盘符冲突。
- 验证手机停止共享、Windows 单击断开、盘符/rclone 清理、有界自动重连和两端手动更新检查。

## 不做什么

- 不因升级验收、当前开发机结果或旧版本清单而判定全新机器通过。
- 不清除手机已有配对或数据；本任务新增一台独立 Windows 电脑身份。
- 不修改代码、Release、标签或公开资产；任一断言失败即停止并保留现场。

## 验收入口

严格按 [v0.2.4 全新机器配对验收清单](../../V0.2.4_CLEAN_MACHINE_ACCEPTANCE.md) 执行。

## 验收结果

未通过。本轮实际执行的是当前 Windows 电脑卸载/重装及 Android 卸载/重装，不是另一台无 PhoneBridge NG 的 Windows 机器，因此不能形成“全新 Windows 机器”证据。

公开 `v0.2.4` Android APK 全新安装后又暴露独立缺陷：未授予通知权限时，第一次点击“配对新电脑”没有出现配对码；返回后第二次点击才出现。日志未发现应用崩溃，源码确认首次点击同时请求通知权限和启动仅配对前台服务，权限弹窗触发 Activity `onPause()`，进而取消尚未激活的配对窗口。验收在未接受配对、Windows 仍为零配对记录时停止。

该缺陷转入 P2-022；P2-021 不记为通过。未来全新 Windows 机器验收必须重新执行，不能沿用本轮结果。

# P1-013 Windows 开机启动生命周期

状态：已完成限定任务。2026-09-21。

## 目标

让用户在 Windows 客户端中明确选择是否随登录启动 PhoneBridge，并验证启动后只有一个托盘实例、只恢复同一已配对设备且可完整关闭。

## 范围

先依据 Microsoft 官方文档选择适用于当前未打包 WPF 客户端的当前用户启动机制；实现默认关闭的中英文设置、启用/禁用、实际登录启动命令校验、损坏入口失败关闭和单实例复用。启动后沿用现有发现、严格身份验证、自动恢复与托盘生命周期。

## 不做什么

不做安装器、系统服务、管理员级自启、计划任务绕过、静默默认开启、自动更新、协议或 Android 改动，不把 PC 重启期间的文件传输列为成功条件。

## 涉及文件

限定在 `windows/src/PhoneBridge.Desktop`、对应测试/资源和项目文档；不得把开发目录或临时 `.audit` 路径写入正式设置。

## 实现

使用当前用户 Run 键，默认关闭；命令为引用后的绝对可执行路径和 `--startup`。注册表是真实状态源，启停后回读确认；同名异常入口不覆盖、不删除。登录启动进入托盘，重复启动静默退出。稳定发现唯一一台与 Active 记录匹配的 PairedV3 手机时，交给既有严格验证和重连监督自动挂载；多台可用时拒绝自动选择。

## 测试

最终 `scripts/Verify-Windows.ps1` 的 Release 构建 0 warnings/0 errors，243 项测试全部通过。当前 Windows 11 上验证默认关闭、用户启停、精确 REG_SZ、应用自身隐藏启动、重复启动保持单实例；Samsung SM-S9180 共享时只运行 `--startup`，6.86 秒自动挂载 P:，桌面和 rclone 各一个。

## 验收结果

限定验收通过。最终 P:、rclone、桌面进程、HKCU 启动项、Android 共享服务和 WakeLock 均不存在。未实际注销/重新登录或重启 Windows，安装路径、升级/卸载清理、两台手机同时在线和非默认盘符偏好未实测，因此 MVP-03 不标完整通过。证据见 [P1-013 验收](../../audit/P1-013-VALIDATION.md)。当时的唯一下一任务为 [P1-014 Windows 日志与诊断包](P1-014-windows-logging.md)，现已完成。

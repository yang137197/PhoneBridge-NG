# P1-030 验收

结果：通过最终需求。Windows 自启动只启动客户端并进入托盘，不自动连接或挂载。

## 已确认

- 共执行 6 次真实 Windows 重启。Startup 文件夹快捷方式能从安装路径以 `--startup` 启动隐藏客户端；第 6 次在用户取消自动挂载要求后终止。
- 已删除启动自动连接、唯一设备选择、启动期配对记录轮询、进程恢复启动器、30/60/150 秒恢复参数和 11 项对应测试。
- 保留手动连接路径和活动连接建立后的网络恢复逻辑；本次没有修改配对、TLS、rclone 挂载或断线恢复模块。
- Samsung 前台共享正常且 TCP 8273 可达时，最终安装版 `--startup` 观察 40.661 秒，只有一个隐藏客户端、0 个 rclone、无 P:，符合“自启动但手动挂载”。
- Release 构建 0 warnings/0 errors；Desktop 51/51、全套 Windows 280/280 通过。验证目录为 `.audit/windows-verification/20260923-121932/`。
- 最新安装器 SHA-256 为 `210A4492F0A78F91AD46C95C1E9E5F09CBCBD12B023CCF1D78EFB4E50C0EF097`；安装 DLL 与发布 DLL SHA-256 均为 `F0FF0BADC9DAB5F18B8E7128CCC972EDEDBBC6E450E204551EB199D533381C09`。

## 历史结论

前 5 次重启围绕已取消的“登录后自动挂载”要求取证，曾确认登录期启动进程读取不到当前配对记录。该事实保留，但不再需要通过延迟、轮询或进程重启解决，因为当前产品不会在登录时读取配对记录以自动连接。

## 判定

MVP-03 按最终需求通过。电脑重启后的盘符挂载由用户手动发起，不再安排自动挂载重启测试。

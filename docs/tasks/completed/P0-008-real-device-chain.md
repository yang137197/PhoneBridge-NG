# P0-008 备用真机同 Wi-Fi 文件链路

- 状态：本轮验证已结束，未通过；完整链路目标待 P0-009 修复后复验
- 目标：使用用户已清空并授权的 Redmi K40，验证修复版在真实 Wi-Fi 上的发现、HTTPS、盘符与双向 100 MB 复制，补齐 Phase 0 的真实网络证据。
- 范围：先重新核对精确 ADB 设备和 Android 版本；核对网络/端点、APK 来源散列及实验共享根，仅使用专用合成数据和独立 Windows 缓存。USB 用于安装与独立散列校验，文件链路实际走 Wi-Fi。
- 不做什么：不使用模拟器专用脚本修改真机 Download 根；不清空设备、不删除非测试文件、不关闭系统保护；不把开发态 TLS 绕过作为真机传输策略，不实现 WPF 或发布安装包。
- 涉及文件：任务与链路证据、必要的明确绑定单一测试机的实验入口；如证据表明需修改核心，先记录缺陷并拆分修复任务。

## 实现

P0-007 已取得用户“已清空，可以用于真机测试”及 USB 调试授权。曾只读核对设备报告 Xiaomi M2012K11AC/alioth、Android 16/API 36，ROM 来源未验证；再次执行前必须实时核对，不能默认 USB 序号始终不变。授权持续有效，无需重复询问可否安装实验 APK。

以最终 P0-007 Debug APK 为候选；安装前确认没有需要保留的同包名安装，保留构建/补丁散列。先确定临时身份验证与真实传输证书校验方法，证书不符/HTTP 降级立即停止。只共享可丢弃的测试区域，不复用正式凭据。

## 测试

按 TESTING 的 CHAIN-01–06：明确实际 Wi-Fi 端点和 mDNS 发现时间；挂载空闲盘符；复制文本及不同区段 100,000,000 字节样本；双向大小和 Android 端独立 SHA-256；记录实际 Explorer 观察及挂载/缓存/服务退出状态。任何未执行或手动备用连接明确区分，不计为自动发现通过。长时间与 1/5/10/20 GB 矩阵不在本任务完成声明内。

## 验收结果

已安装并核对 P0-007 实验 APK；用户完成正常通知授权并启动 Music 共享。mDNS 从监听开始 0.218 秒发现手机。实际 rclone 在开启证书校验时因证书无 IP SAN 拒绝连接，退出 1；未挂载、未复制或发送凭据。应用已停止、转发移除、端口关闭，保留安装。

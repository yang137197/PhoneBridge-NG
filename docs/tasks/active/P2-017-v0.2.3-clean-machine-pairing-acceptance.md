# P2-017 — v0.2.3 全新机器配对验收

状态：待开始。日期：2026-09-28。

## 目标

在一台没有 PhoneBridge NG 的 Windows 11 x64 机器上，只使用 GitHub Release `v0.2.3`，验证首次安装、全新电脑配对、备注卷名、盘符分配、停止共享和有界自动重连。

## 范围

- 核对 GitHub Release 六项正式资产及 SHA-256，不使用本地候选或 Debug 制品。
- 验证 Windows/WinFsp 首装、Android 正式 APK、启动后不自动挂载和新的 8 位码配对。
- 验证设备名/设备备注、挂载汇总、停止共享状态、Explorer 盘符清理、Auto 顺序和配对后固定盘符设置。
- 验证活动连接临时断网在预算内恢复同一身份和原盘符；明确停止共享后 2 分钟内结束恢复，重新共享仍需手动连接。
- 按 [v0.2.3 全新机器验收清单](../../V0.2.3_CLEAN_MACHINE_ACCEPTANCE.md) 保存版本、哈希、截图和必要日志证据。

## 不做什么

- 不清除手机现有数据或配对，不为制造干净环境破坏日常机器。
- 不重测无关的 5/10/20 GB、睡眠、手机重启或双设备大文件矩阵。
- 不修改代码、Release、标签或正式资产来绕过验收失败。

## 停止条件

制品摘要不一致、安装或配对失败、身份/凭据异常、出现重复盘符或 rclone、固定盘符冲突时静默换盘、停止共享后继续无限重连，或安全断开无法确认时立即停止并保留现场。

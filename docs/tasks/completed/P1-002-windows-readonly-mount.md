# P1-002 Windows rclone 进程托管与只读挂载

- 状态：已完成限定任务；不代表完整客户端或 MVP 完成。
- 目标：在 C# 中托管一个有界、可正常退出的 rclone 只读挂载会话，能区分启动失败、运行、卸载和异常退出。
- 范围：先记录会话/信任输入和生命周期边界，检测已安装 WinFsp、锁定 rclone 版本/哈希、检查空闲盘符；先测进程行为，再以已授权备用机和 P0-010 合成目录作只读验证。
- 不做什么：不自动配对/挂载发现候选，不启用读写/删除，不保存明文凭据，不改变驱动或系统信任库，不发布安装包。
- 涉及文件：Windows MountManager/RcloneManager 最小模块、相关测试和任务证据；发现层保持既有接口与行为。

## 实现

`DeviceCandidate` 不得直接成为可挂载会话。实验输入须明确携带通过既有授权 USB 核对的设备公有 CA 和临时内存凭据，真实 rclone 每次使用设备专属 ca-cert 与地址校验；不使用 no-check-certificate，不把实验 USB 引导称为正式配对。正式配对与长期凭据生命周期继续由 D-03 单独处理。

只能管理本模块创建并记录的子进程及盘符；禁止按进程名称批量终止。退出先请求正常卸载，超时和失败必须可观察；不能把仍运行的挂载报告成卸载完成。实验只读，不涉及 D-06 的待上传数据恢复。

## 测试

有意义的进程/状态测试：路径含空格、无效参数、启动失败、重复启动、并发退出、超时/异常、取消与输出脱敏。实机检查指定合成目录可读、写入被拒绝、正常卸载后盘符和所属子进程均消失；保留既有样本，不重复大文件复制。

## 验收结果

已实现只读挂载库与机器 JSON 诊断入口；最终构建 0 warnings / 0 errors，74 项测试、12 项真机检查通过。创建时绑定 Job，正常退出/宿主异常退出均核对盘符与所属子进程；样本、元数据和身份保留。失败入口和代码复核修正分别记录于 [验收报告](../../audit/P1-002-VALIDATION.md)。正式配对、安全保存、UI/重连未实现，不宣称日常可用客户端或 MVP 完成。下一任务为 P1-003 配对与凭据生命周期设计。

# P2-030 — v0.2.6 正式候选与首次引导验收

状态：进行中。日期：2026-09-30。

## 目标

把 P2-026 至 P2-029 的更新反馈和首次使用引导纳入版本递增的正式签名候选；以候选之前最近一个资产完整正式 Release 为动态基线完成 Windows/Android 原位升级，并验证全新数据状态下的首次引导。

## 范围

- 实时解析最近一个非草稿、非预发布、资产完整的正式 Release，记录标签、提交及资产 SHA-256。
- 将 Windows、Android、交付脚本和安装说明统一递增到 `0.2.6`；Android `versionCode` 递增并继续使用同一正式签名身份。
- 生成 Windows 安装器、正式 APK、对应源码 ZIP、README、SHA256SUMS 和 manifest，并核对文件集合、版本、签名及摘要。
- 先从真实前一正式版本完成 Windows/Android 原位升级，验证版本、签名、配对、设置、不误弹首次引导、更新入口、基础连接、文件访问及安全断开。
- 在不冒充全新 Windows 机器的前提下，以明确的全新应用数据状态验证 Windows/Android 首次引导、永久帮助入口及首次配对主流程。

## 不做什么

- 不增加 P2-026 至 P2-029 以外的新功能。
- 不把当前电脑清除应用数据称为全新 Windows 机器验收。
- 不绕过签名、摘要、前一正式版本或原位升级门禁。
- 不推送分支、不创建标签或 GitHub Release；发布必须另行获得明确授权。

## 涉及文件

- Windows/Android 版本源、更新策略测试及 UI 预览版本。
- `scripts/Build-LocalDelivery.ps1`、`scripts/New-SourceDelivery.ps1`。
- `docs/INSTALL_LOCAL.txt`、`docs/LOCAL_DELIVERY.md`。
- 当前任务、README、交接和候选验收证据。

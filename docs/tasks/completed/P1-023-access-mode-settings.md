# P1-023 三种访问模式与用户设置收口

状态：已完成。验收日期：2026-09-22。

## 目标

让用户在手机端为每台已配对电脑选择只读、安全或完全读写模式，并让 Windows 明确显示服务端确认的当前模式，完成产品已有三种安全策略的实际入口。

## 范围

复用 Android `PairingStore.updateMode`、现有 session mode 回读和 Windows 挂载参数，不新增协议。手机端在已配对电脑列表中提供三种模式选择，默认保持安全模式；变更后使旧连接失效并由下一次严格 session 应用。Windows 只显示手机确认的模式，不自行提高权限。中英文文案同时完成。

使用一个已配对 Samsung 测试设备，分别做最小验证：只读拒绝新建、安全模式允许新建但不替换既有文件、完全读写允许受控覆盖。每种模式一次即可。

## 不做什么

不新增回收站、多设备同时挂载、远程账号、复杂权限模板或额外安全模式。不重复大文件、视频、名称排列组合或无关回归；只运行受影响模块和一次现有 Windows 回归入口。

## 涉及文件

- Android 已配对电脑界面、资源与模式更新调用。
- Windows 当前模式显示与现有本地化资源。
- 对应 Android/Windows 最小行为测试和验收摘要。

## 实现

Android 已配对电脑列表加入三种模式选择器，复用 `PairingStore.updateMode`；提交后关闭该电脑的旧连接。Windows 增加手机确认模式列；健康检查发现模式变化时保存已验证的新模式、安全卸载旧盘符并要求重新连接。协议和权限类型没有变化。

## 测试

固定 Android 构建/Lint 通过，Samsung 定向 instrumentation 1/1；Windows Connection 18/18、Desktop 50/50、完整回归 279/279，Release 构建 0 warnings/0 errors。Samsung 真机逐一验证只读拒绝新建、安全允许新建但不覆盖、完全读写允许受控覆盖。

## 验收结果

通过限定范围。模式最终恢复为安全模式，专用样本和两端运行资源均已清理。证据见 [P1-023 验收](../../audit/P1-023-VALIDATION.md)。唯一下一任务为 P1-024 本地可安装交付包。

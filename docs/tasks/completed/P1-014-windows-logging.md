# P1-014 Windows 日志与诊断包

状态：已完成限定任务。2026-09-21。

## 目标

为 Windows 客户端加入统一、可轮转、默认本地保存的结构化日志，并允许用户明确导出经过脱敏的诊断包，用于定位发现、认证、挂载、卸载和重连问题。

## 范围

记录必要的应用版本、设备发现状态变化、认证结果码、挂载/卸载、rclone 退出、WinFsp 状态、网络失败和重连；提供中英文“导出诊断包”入口。日志和诊断包有大小/数量上限、原子导出和字段白名单，失败时保留原日志。

## 不做什么

不上传日志，不加入遥测、账号、崩溃采集服务或远程服务器；不记录密码、Token、认证 Header、私钥、用户文件内容、完整文件路径或未经处理的异常原文。不修改 Android、协议、安装器、自动更新或大文件行为。

## 涉及文件

修改 Windows Desktop 的日志/导出模块、必要事件接入、WPF 资源和测试，并更新架构、决策、测试与验收文档；未引入第三方运行时依赖。

## 实现

日志使用受保护的当前用户目录、固定字段 JSONL、1 MiB × 5 轮转和失败隔离。诊断包由用户明确选择位置，仅含 manifest 与日志快照，使用同目录临时文件和原子移动提交。WPF 接入发现、认证、连接、挂载、rclone、WinFsp、网络、重连、托盘与自启动事件，不记录原始异常或设备/网络/路径身份数据。

## 测试

最终 Release 构建 0 warnings/0 errors，254/254 项 Windows 测试通过。实际中文 WPF 导出包仅含两个白名单条目，3 行日志全部可解析，禁止字段与秘密模式扫描为 0，导出后日志继续写入。

## 验收结果

限定验收通过。实际磁盘满/权限撤销、5 MiB 完整轮转、英文系统人工导出和全部真实故障事件序列未逐项运行。证据见 [P1-014 验收](../../audit/P1-014-VALIDATION.md)。后续任务 [P1-015 Windows 手动地址排障入口](P1-015-windows-manual-endpoint.md)现已完成。

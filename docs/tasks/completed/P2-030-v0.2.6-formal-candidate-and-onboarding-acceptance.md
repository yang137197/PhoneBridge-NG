# P2-030 — v0.2.6 正式候选与首次引导验收

状态：已完成。日期：2026-09-30。

## 目标

把 P2-026 至 P2-029 的更新反馈和首次使用引导纳入版本递增的正式签名候选；以候选之前最近一个资产完整的正式 Release 为动态基线完成 Windows/Android 原位升级，并另行验证双端全新应用数据安装。

## 范围

- 实时解析最近一个非草稿、非预发布、资产完整的正式 Release。
- 将 Windows、Android、交付脚本和安装说明统一递增到 `0.2.6`；Android `versionCode=8`。
- 生成并核验安装器、正式 APK、对应源码 ZIP、README、SHA256SUMS 和 manifest。
- 验证正式前版原位升级的版本、签名、配对、引导迁移、连接、文件访问和安全断开。
- 在不冒充全新 Windows 机器的前提下，验证双端清除应用数据后的首次引导、帮助、配对和基础主链路。

## 不做什么

- 不增加 P2-026 至 P2-029 以外的新功能。
- 不把当前电脑清除应用数据称为全新 Windows 机器验收。
- 不绕过签名、散列、前一正式版本或原位升级门禁。
- 不推送分支、不创建标签或 GitHub Release。

## 验收结果

通过。

- 双端全新应用数据安装：自动显示完整四步引导，Windows“关于 → 使用帮助”和 Android“设置 → 使用帮助”可重新显示完整内容；无旧配对状态下真实配对、共享、连接、E: 挂载、文件读取和断开通过。

## 未验证与限制

- 本轮的 Windows 全新安装是当前电脑清除应用数据后完成，不是全新 Windows 机器证据。
- 由于 v0.2.6 尚未发布，无法在已安装 v0.2.6 上从 GitHub Latest 下载更新的正式版；Windows/Android 对“当前已是最新版本”的真实检查已通过，下载进度的真实新 Release 视觉验收需在后续存在更新正式版时完成。
- 全新配对后曾出现一次首次连接失败，随后连接和再次断开/连接均通过，原位升级验收也是首次成功；未能复现，暂无证据将其记为产品缺陷。

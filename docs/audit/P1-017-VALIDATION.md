# P1-017 5 GB 双向传输完整性验收

日期：2026-09-21  
结果：通过限定范围。

## 环境与边界

- Windows 11、WinFsp、项目固定 rclone 1.75.1、Release 构建。
- Samsung SM-S9180，Android API 36，实际共享根为 `Music`。
- 两个样本均为精确十进制 5,000,000,000 字节。
- 文件通过 P: 的 WinFsp/rclone 挂载路径复制；本轮没有人工 Explorer 拖放。
- 不执行 Wi-Fi 中断、睡眠、重启、磁盘满、播放或随机 Seek。

## 样本工具修正

首次生成暴露两个仅在大于 2 GiB 时出现的测试工具问题，均在开始传输前定位并修正：

1. PowerShell 的 `Math.Min` 被绑定到 32 位重载，5,000,000,000 无法转换。改为显式 64 位重载后，生成文件长度和二次 SHA-256 与流式生成结果一致。
2. Android shell 在第 2148 段执行 `i * 1000000` 时发生 32 位溢出，`dd` 报 `bad -2146967296`。改为十进制字符串偏移 `${i}000000` 后完成全部 5,000 段。

手机样本先创建精确 5 GB 逻辑长度的稀疏零文件，再在每个 1,000,000 字节段首写入不同标记。稀疏只减少测试准备阶段的闪存写入；实际 P: 传输和 SHA-256 均完整读取 5,000,000,000 字节。

## 手机到 PC

手机端独立生成并计算 SHA-256：`041eb9931a3d9157533a743bb9cad82d1089e38a04adf5d38e81f1e9cea488a5`。通过 P: 使用无缓冲复制到 PC，耗时 91,711 ms。复制结束后 Windows 文件长度精确为 5,000,000,000 字节，独立 SHA-256 相同。期间桌面端保持响应，P: 存在且只有一个 rclone。

## PC 到手机

PC 流式生成样本 SHA-256：`e2558bd9d1fb5616b0a2370513335cf16d2f781039d6bc0f02c2a38df57a991b`。写入本地 VFS 缓存耗时 7,269 ms；手机端在上传期间只有一个 `.phonebridge-upload-*` 临时文件，没有提前出现最终目标。78,966 ms 后原子最终文件出现，临时文件计数归零。

Android 独立读取最终文件，长度为 5,000,000,000 字节且 SHA-256 与 PC 源相同。Windows 固定缓存元数据为 `Dirty: false`。随后安全卸载耗时 3,789 ms，P: 和 rclone 均消失。

## 自动回归与清理

Release 构建 0 warnings、0 errors；Windows 273/273 测试通过。结构化摘要见 [large-file-live.json](p1-017/large-file-live.json)。手机任务目录、PC 两个 5 GB 样本和本任务两个缓存/元数据文件已精确删除；P:、rclone 和桌面端均不存在。用户停止共享后，Android 服务列表为空、活动通知消失、当前 Wake Locks 中无 PhoneBridge 项，且手机本机连接 8273 返回 `Connection refused`。Android 仍保留应用进程，但没有上述活动共享组件。

## 必须在稳定第三方分发前完成

### 1. Android 长期发行签名

`Build-LocalDelivery.ps1` 虽可接收 keystore 路径，但仍硬编码别名 `androiddebugkey`、Debug 密码和 `local-test` 产物语义。manifest 也明确写明“not for public release”。这会把产品更新连续性绑定到开发机 Debug key，不能作为稳定第三方发行签名路径。

下一任务必须让发行签名参数显式输入、秘密不进入命令输出/manifest/仓库、缺失或误用 Debug 证书时失败关闭，并把本地测试构建与发行构建分开。实际长期私钥的保存和备份位置需在生成前形成具体边界。

### 2. 无 WinFsp 的干净 Windows 安装证据

安装器已内置固定、NAVIMATICS 签名有效的 WinFsp 2.1.25156 MSI，并实现缺失时提权安装及失败关闭；但 P1-024 明确记录当前电脑已有 WinFsp，因此该分支没有真实运行。本机也没有 Windows Sandbox 或 Hyper-V 测试面。不能为了补证卸载当前正在使用的驱动；应在可用的干净 Windows 环境出现后只执行一次首装验收。

- 手动地址用于已有配对身份，首次配对仍依赖 mDNS；当前家庭局域网主流程已通过，此项只有出现真实首次发现故障时再提升。

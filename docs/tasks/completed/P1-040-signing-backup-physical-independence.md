# P1-040 — 签名备份物理独立性检查

状态：已完成代码。日期：2026-09-23。

## 目标

修复长期签名初始化只检查目录关系、可能把同一物理磁盘上的另一个分区误当独立备份的问题。

## 范围

初始化前识别主密钥和备份路径的存储类型；主密钥要求本地固定磁盘，备份只接受可移动卷、不同物理磁盘的固定卷或网络卷。同一物理磁盘无论盘符是否不同都失败关闭。

## 不做什么

不生成正式私钥，不连接或格式化存储，不创建网络共享，不推断网络存储后端是否真的物理独立，不改变发行构建或产品运行代码。

## 涉及文件

- `scripts/Initialize-AndroidReleaseSigning.ps1`：存储分类和物理磁盘检查。
- `docs/LOCAL_DELIVERY.md`、`DECISIONS.md`：操作边界。
- 本任务、验收记录和机器可读证据。

## 实现

- 新增路径存储分类：UNC 或映射网络卷为 `network`，可移动卷为 `removable`，固定卷进一步解析 `DiskNumber`。
- 主签名目录必须位于本地固定磁盘；网络或可移动主目录拒绝。
- 固定卷备份与主目录 `DiskNumber` 相同即拒绝，盘符不同不能绕过；不同固定磁盘、可移动卷和网络卷可继续后续检查。
- 存储检查位于目录创建、密码读取和 keytool 之前，失败不会创建密钥或目标目录。
- 成功输出将记录非秘密的主/备份存储类型，不记录物理设备名称或序列号。

## 测试

- PowerShell 语法解析通过。
- 当前 C: 与 D: 都映射 Disk 0；C: 主目录配 D: 备份返回 1，并命中“必须位于不同物理磁盘”。
- 同一 C: 卷的两个非嵌套目录同样返回 1，证明不仅依赖盘符比较。
- UNC 网络路径作为主目录返回 1；不存在的 Z: 备份卷返回 1。
- 四项拒绝均发生在创建目录前；测试路径存在数量为 0，正式身份未创建。
- 外置存储正向生成未运行：当前物理磁盘 1、可移动卷 0、映射网络卷 0。
- 更新说明后的默认 `LocalTest` 交付重建成功：安装器 SHA-256 `B357083FD1B53491BE9F7C2E1378450B31BAC7FBA47EF63363D39F9158F280A1`，APK散列保持 `B6831F1C580C1337E9A0FDC4DB8BB21FD328AE90D9E0C2625DB61D170C6D33BC`。

## 验收结果

同盘误备份缺陷已失败关闭。由于没有可用独立存储，本任务不能证明外置磁盘正向生成；该项将与正式长期身份创建在真实介质接入后一起验收。

# P2-002 — 两端线框、控件状态、视觉变量与图标概念

状态：**图标 A 已由用户选择并冻结；其余静态候选等待用户确认**。日期：2026-09-24。

## 目标

在不修改业务代码的前提下，制作并冻结 Windows/Android 静态线框、控件状态、视觉变量和三个原创图标概念，供用户确认。

## 范围

- Windows 六页线框：设备主页、添加手机、设备设置、常规设置、高级排障、关于。
- Android 四页线框：首页、配对会话、电脑详情、设置。
- Windows 设备卡片五态矩阵及通用控件状态。
- 色彩、字号、间距、圆角、按钮层级、状态色和最小图标尺寸。
- 三个原创 SVG 图标方向及 32/16 px 简化说明。
- 简体中文主稿和 English 关键路径映射。

## 不做什么

- 不修改 Windows/Android 业务代码、资源、构建配置或交付二进制。
- 不开始按设备隔离的多会话重构。
- 不增加多主题、二维码配对、云服务、同步或其他功能。
- 不运行与静态文档无关的构建、回归或真机测试。

## 实现

冻结候选使用冷灰页面、白色单层卡片、科技蓝主色、青色连接强调、独立语义状态色和两端一致的圆角线性图形语言。Windows 主路径收口为“添加手机 / 配对 / 连接 / 打开文件 / 断开”，危险与排障操作移入对应设置；Android 首页只保留共享状态、目录、一个开始/停止主按钮、配对入口和已配对电脑。

图标提供 A“桥接文件”、B“双端连接”、C“文件入口”三个原创方向。候选 A 在语义完整性与 16 px 独特轮廓之间最平衡；用户已在 2026-09-24 明确选择 A。B/C 继续保留为设计比较记录，不进入正式资产方向。

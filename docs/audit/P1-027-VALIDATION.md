# P1-027 大量照片目录性能验收

日期：2026-09-22。结果：通过。设备为 Samsung SM-S9180/API 36，使用 Android `0.1.0` 和 P1-024 Windows 最终安装版。没有读取真实照片，也没有修改产品代码。

## 预先固定的通过线

- 共享启动到 P: 挂载不超过 30 秒。
- Explorer 窗口在 5 秒内创建并保持响应。
- 首次完整枚举 5,000 项不超过 15 秒，10,000 项不超过 30 秒。
- 同一会话第二次完整枚举不超过 5 秒。
- 不得出现重复 P:、重复桌面客户端/rclone、客户端崩溃或无法安全停止。

这些阈值写入任务后才开始生成数据，没有按结果放宽。

## 测试数据

测试目录固定为 `Music/PhoneBridge-P1-027`。每个文件均为相同的 96×96、812 字节有效基线 JPEG；样本 SHA-256 为 `E05E945BF44405D52E354832F20DCF2FFACB64383988D97E7EC8D196C384FB35`。Android 独立计数依次确认 5,000 和 10,000 个 `PB-*.jpg`。数据生成时间不计入产品挂载或浏览性能。

## 结果

| 项目 | 5,000 项 | 10,000 项 | 阈值 | 结果 |
| --- | ---: | ---: | ---: | --- |
| 共享至 P: | 5.944 秒；新会话复验 2.982 秒 | 2.628 秒 | ≤30 秒 | 通过 |
| 首次完整枚举 | 0.520 秒 | 1.072 秒 | ≤15/30 秒 | 通过 |
| 同会话完整枚举 | 0.570 秒 | 0.047 秒 | ≤5 秒 | 通过 |
| Explorer | 实际显示 `5,000 个项目`，保持响应 | 2.155 秒显示 `10,000 个项目`，保持响应 | ≤5 秒 | 通过 |

全程只有一个 `PhoneBridge.Desktop`、一个 rclone 和一个 P:。观察到的峰值工作集为桌面客户端 210,087,936 字节、rclone 73,621,504 字节；两者和 Explorer 均保持响应。

Android UID 网络统计仅用于观察：5,000 项阶段接收 110,338、发送 5,935,904 字节；10,000 项阶段接收 80,809、发送 7,770,302 字节。统计包含挂载、枚举和 Explorer 元数据流量，未将其解释为纯缩略图流量，也没有追加测后阈值。

两次完整安全停止的盘符卸载观察值为 22.139 和 23.405 秒。任务没有预设停止时延门槛；两次最终都清除 P: 与 rclone，没有僵尸或重复资源。

## 清理与边界

结束时先停止共享并确认 P:/rclone 消失，再删除精确隔离目录与手机临时归档。Android 回读目标目录不存在，Music 顶层项目数恢复为测试前的 2。最终 8273、P:、PhoneBridge Windows 客户端、rclone 和测试 Explorer 窗口均不存在。

原始结构化证据保存在被忽略的 `.audit/runs/P1-027/`。没有改动产品代码，因此没有重复 P1-024 已通过的 Windows 279/279 和 Android 123 个 Gradle task。结论只覆盖 10,000 个小型有效 JPEG 的目录/元数据路径，不代表真实大照片解码、内容吞吐或超过 10,000 项的性能。

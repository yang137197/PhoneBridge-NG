# P2-010 — v0.2.2 盘符显示名与设备级分配

状态：实现完成，自动验证通过。日期：2026-09-28。

## 目标

让 Windows 资源管理器按设备备注/设备名称显示挂载盘，并让多设备在 USB、网络盘和既有 PhoneBridge 会话共存时使用可预测、可持久修改的盘符策略。

## 已实现

- 配对记录 schema 升为 3，新增设备级盘符偏好：默认 Auto，或固定 D–Z；schema 1/2 继续可读并迁移为 Auto。
- Auto 在每次新连接时按 D→Z 选择首个不被 Windows 使用且未被其他 PhoneBridge 会话预留的盘符；选择和会话预留在协调器内原子完成。
- 固定盘符发生系统占用或会话冲突时失败关闭，不静默回退；用户主动断开会释放预留，进程内自动重连继续使用原预留。
- 设备设置可同时保存设备备注和盘符偏好；已挂载时修改只影响下次连接，不强制重挂或中断传输。
- rclone 网络卷共享名由设备备注优先、设备名称兜底，并清洗 Windows 非法字符、尾随点/空格和过长 UTF-16 名称；服务器名由设备证书摘要派生，保证同名设备可区分。
- Windows 桌面、Android 和隔离候选元数据升至 `0.2.2`。当前 `v0.2.0` 正式源码交付脚本增加版本守卫，避免把后续源码误标为 `0.2.0`。

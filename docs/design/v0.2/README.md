本目录是 P2-002 经用户确认的静态设计基线。P2-003 已生成对应的 WPF/Android 原生验收候选，当前仍以本目录的确定性 SVG、状态、变量和文案作为视觉判断基线；候选尚未得到用户最终视觉确认。

- Windows：设备主页、添加手机、设备设置、常规设置、高级排障、关于。

- Windows 设备卡片五种状态及其唯一主操作。
- 两端共用的视觉变量、按钮层级、状态表达和图标尺寸。
- 三个原创图标方向用于选择；P2-003 已生成 A 的 Windows 应用和 Android 启动器候选资产，安装器与完整托盘状态资产留到 P2-006。
- 简体中文主稿及 English 关键文案映射。

不增加主题选择、云服务、账号、同步、二维码配对、文件浏览器或任何未确认功能。

## 3. 冻结的信息架构

### Windows

- 左侧导航固定为“设备 / 设置 / 关于”。
- 首页不常驻配对码、IP、端口、删除路径或九个并列按钮。
- “添加手机”流程固定为：选择手机 → 输入 8 位码 → 等待手机批准 → 自动连接。
- 日常主路径固定为：连接 → 打开文件 → 断开。
- 危险操作进入“设备设置”，网络排障和诊断进入“设置 → 高级排障”。

### Android

- 首页固定呈现共享状态、共享目录、一个开始/停止主按钮、配对入口和已配对电脑。
- 配对码和批准操作只在配对会话存在时出现。
- 访问模式和撤销授权只在对应电脑详情中出现。
- 设置为独立菜单；本版菜单只进入语言子页，不增加主题选择器。

- Windows 六页已在本机 WPF 实际渲染；Android 首页与设置页已在 Samsung 真机回读。Android 配对会话和电脑详情尚未形成可验收的真实状态。

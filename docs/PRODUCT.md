# 产品范围与验收

状态：需求基线，来源为 [AGENTS.md](../AGENTS.md)。**本文件描述目标，不描述已交付能力。** 当前进度见 [README](../README.md)。

## 用户与问题

面向希望在 Windows Explorer 中直接管理 Android 共享文件、无需云账号或每次输入地址/密码的用户。主要验证设备为 Windows 11 PC 与 Samsung Galaxy S23 Ultra，代码不绑定该型号。

核心仅做无线访问 Android 文件。优先级依次为：稳定、数据安全、文件系统兼容、简单、性能、UI、附加功能。

## 使用目标

首次安装时检测依赖，发现手机并完成配对。用户在 Windows 客户端中选择已配对手机并点击连接后，验证身份并出现手机盘符；活动连接因短暂网络故障中断时可自动重新验证和挂载。Windows 自启由用户选择，自启只启动客户端并进入托盘，不自动连接或挂载；电脑重启后由用户手动点击连接。关闭主窗口默认进入托盘。

访问目标为 DCIM、Pictures、Download、Documents、Movies、Music、Android/media；实际范围取决于系统权限。不承诺 `/data/data`、其他 App 私有目录或系统限制的 Android/data。Android 安装下限为 API 26，本阶段 targetSdk 36；后台能力以已记录的系统和厂商限制为准。

## MVP 范围

| 部分 | 必需能力 |
| --- | --- |
| Android | 开始/停止共享、权限管理、HTTPS/WebDAV、mDNS、设备名称、配对、前台服务、中文资源 |
| Windows | 自动发现/手动 IP 排障、配对、安全凭据保存、rclone/WinFsp 检测与调用、手动连接挂载、卸载、活动连接重连、Explorer 打开、托盘、日志、中文资源 |
| 文件操作 | 列目录、打开、双向复制、创建目录、重命名、按当前权限模式删除 |
| 安全默认 | 默认安全模式；另有只读、完全读写；删除确认、证书身份绑定、系统安全存储；详见 [SECURITY](SECURITY.md) |
| 配套交付 | Windows 单入口安装体验（依赖可官方引导）、GitHub Release APK、诊断包、自启选择；发行与依赖验证必须如实记录 |

不引入云盘、用户账号、广告、遥测/分析 SDK、会员、聊天、通知同步、投屏、剪贴板同步、AI、NAS、文件在线编辑、Root、自建驱动。Tailscale 远程访问不移入本阶段；自动更新、专用缩略图优化与回收站自动清理留待后续。

第一阶段使用 Explorer 自带缩略图能力；大目录读取量和 UI 响应仍要测量，不能以“不开发缩略图服务”为由跳过性能观察。

## MVP 必须通过的 15 项

编号对应 AGENTS 第 30 节，不减少或替换原有验收。

| ID | 场景 | 通过标准 | 当前结果 |
| --- | --- | --- | --- |
| MVP-01 | 同 Wi-Fi 发现 | 共享可用、扫描启动后 30 秒以内发现设备；记录计时起止 | 通过：Redmi 发现为 3.890 秒；P1-025 当前安装版连接 Samsung 并挂载为 6.352 秒，均在同一 LAN，见 P1-001、P1-025 |
| MVP-02 | 首次配对 | 用户完成一次性配对并绑定真实设备身份 | 备用 Redmi K40 与 Samsung SM-S9180/API 36 均通过限定实测，见 P1-008、P1-011 验收 |
| MVP-03 | Windows 自启 | 用户启用自启后，登录时只启动唯一客户端并进入托盘；不得自动连接、自动挂载或启动 rclone，盘符由用户手动连接后出现 | 通过：P1-030 的真实重启确认 Startup 快捷方式能启动安装版；按最终需求删除全部启动自动连接和恢复逻辑后，手机在线共享且 8273 可达时，安装版 `--startup` 观察 40.661 秒仍为一个隐藏客户端、0 个 rclone、无 P:；280/280 Windows 测试通过 |
| MVP-04 | Android 重启 | 不要求重启期间传输；手机解锁并由用户重新开始共享后，Windows 能恢复且未损坏既有文件 | 通过：P1-026 Samsung 实际 boot ID 变化，解锁并重新共享后 7.289 秒恢复唯一 P:；目录清单、样本哈希和配对记录保持 |
| MVP-05 | 常用目录 | DCIM、Download、Pictures 均能正常打开 | 通过：P1-025 安装版依次挂载，P: 与 Android 顶层列表分别 3/3、5/5、19/19 全部对应 |
| MVP-06 | 复制大小覆盖 | 100 MB、1 GB、5 GB 均复制成功，大小/两端哈希一致 | 通过：P0-010、P1-016、P1-017 的双向精确长度与两端独立 SHA-256 一致 |
| MVP-07 | PC 上传 | Explorer 上传后手机文件实际存在且内容一致，不只停在 PC 缓存 | 通过：P1-009 Explorer 小文件及 P1-016/P1-017 大文件均由 Android 独立确认落盘、长度和哈希 |
| MVP-08 | 重命名 | 新名称可见、旧名称消失、文件内容保持 | 通过：P1-022 的 Samsung P: 重命名后，新名称内容/哈希保持且旧名称消失 |
| MVP-09 | 创建目录 | 手机实际创建目录并可在 Explorer 重新列出 | 通过：P1-009 Explorer 创建/重命名目录，Android 独立确认目标存在 |
| MVP-10 | 删除 | 在安全模式经明确确认后完成；未确认时拒绝，不能绕过服务端保护 | 通过：P1-009 过期确认拒绝且目标保留；新确认后文件和目录删除，Android 独立确认不存在 |
| MVP-11 | 复制时断 Wi-Fi | 不要求中断期间继续传输；Windows 客户端不崩溃，未完成目标不冒充成功，缓存和手机文件状态可核对 | 通过：P1-016 的 1 GB 上传中断时客户端未崩溃、最终目标不存在、缓存明确为 Dirty |
| MVP-12 | 网络恢复 | 能自动重新验证/连接，不重复挂载 | 通过：P1-010 安全卸载后按同一身份恢复单一 P:/rclone；P1-016 原会话恢复并提交脏缓存 |
| MVP-13 | 手机 IP 改变 | 通过 mDNS 找回同一已配对设备并恢复连接 | 通过：P1-028 Samsung 从 `192.168.100.238` 变为 `.171`；mDNS 更新同一候选，三次健康失败后安全卸载并在 34.117 秒恢复唯一 P:，保存身份和目录清单不变 |
| MVP-14 | PC 睡眠/唤醒 | 不要求睡眠期间传输；唤醒后能恢复连接，无僵尸或重复进程/盘符，未完成文件状态可核对 | 通过：P1-029 本机实际 S3 睡眠 158.656 秒，唤醒后原进程和唯一 P: 保持，4.550 秒恢复健康；实际文件读取、目录清单和配对记录一致 |
| MVP-15 | 大量照片目录 | 5,000/10,000+ 条目下可操作，UI 不长时间假死；记录客观时延 | 通过：P1-027 Samsung 10,000 个有效合成 JPEG 下 2.628 秒挂载、1.072 秒首枚举、0.047 秒复枚举，Explorer 2.155 秒显示完整数量且保持响应 |

MVP-15 的量化时延阈值已在测试前由 DECISIONS ADR-028 固定并由 P1-027 满足。Windows 登录后的自动挂载已由用户明确移出产品范围；这不改变活动连接发生短暂网络中断时的自动恢复能力。

除以上 15 项，还必须满足 AGENTS 的安全、数据完整性及 10/20 GB、播放 Seek、其他故障情形要求，见 [TESTING](TESTING.md)。15 项是必要条件；存在阻塞性数据丢失或身份验证缺陷时不得称 MVP 完成。

## 交付状态判定

源码存在、mock 通过、模拟器验证、备用真机和三星真机验证分别记录；不互相替代。P1-025 逐条回读 P0-010、P1-001 至 P1-024 的原始验收范围并补测三个常用目录；P1-026 完成 Samsung 实际重启恢复，P1-027 完成 5,000/10,000 项目录性能验收，P1-028 完成真实手机 IP 变化恢复，P1-029 完成本机 S3 睡眠/唤醒恢复。P1-030 按最终需求删除 Windows 登录自动挂载及其恢复测试，自启动只进入托盘并等待用户手动连接。当前 MVP-01–15 共 15 项通过；证据见 [P1-025 映射](audit/P1-025-VALIDATION.md)、[P1-026](audit/P1-026-VALIDATION.md)、[P1-027](audit/P1-027-VALIDATION.md)、[P1-028](audit/P1-028-VALIDATION.md)、[P1-029](audit/P1-029-VALIDATION.md)和 [P1-030](audit/P1-030-VALIDATION.md)。P1-042 已完成正式 Android 签名版本的 Samsung 迁移与同签名覆盖升级，P1-043 已将同一产物提升为默认交付。当前 Windows 客户端可发现和保存多台手机，但只允许一个活动挂载；同时多设备共享不属于当前 MVP-01–15。

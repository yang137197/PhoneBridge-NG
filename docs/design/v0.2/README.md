- Windows：设备主页、添加手机、设备设置、常规设置、高级排障、关于。

- 三个原创图标方向，仅用于选择；正式平台资产留到 P2-006。
- 简体中文主稿及 English 关键文案映射。

不增加主题选择、云服务、账号、同步、二维码配对、文件浏览器或任何未确认功能。

## 3. 冻结的信息架构

### Windows

- 左侧导航固定为“设备 / 设置 / 关于”。
- 首页不常驻配对码、IP、端口、删除路径或九个并列按钮。
- “添加手机”流程固定为：选择手机 → 输入 8 位码 → 等待手机批准 → 自动连接。
- 日常主路径固定为：连接 → 打开文件 → 断开。
- 危险操作进入“设备设置”，网络排障和诊断进入“设置 → 高级排障”。

### Android

- 首页固定呈现共享状态、共享目录、一个开始/停止主按钮、配对入口和已配对电脑。
- 配对码和批准操作只在配对会话存在时出现。
- 访问模式和撤销授权只在对应电脑详情中出现。
- 设置页本版只增加语言选择；不增加主题选择器。

## 5. 已知边界

- 静态稿未在 WPF、Android 真机、不同 DPI、系统字体放大或高对比度下渲染。
- 色彩对比度、键盘焦点、屏幕阅读器名称和触控目标尚未通过实现级测试。
- English 仅冻结关键路径文案；实现时仍需覆盖现有全部错误、通知、托盘和对话框资源。
- 图标尚未导出 `.ico`、Android adaptive icon、Android 13 monochrome 或安装器资产。
- 多设备同时挂载仍未实现；线框只描述预期的独立设备卡片。

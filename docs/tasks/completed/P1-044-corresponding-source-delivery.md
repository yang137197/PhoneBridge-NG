# P1-044 — 正式对应源码交付包

状态：已完成。日期：2026-09-23。

## 目标

为当前 PhoneBridge NG 0.1.0 正式二进制交付生成不含私钥、密码、构建缓存或本地审计目录的完整对应源码 ZIP，并把它纳入默认交付 manifest 与 SHA256SUMS。

## 范围

- 包含 Android、Windows、脚本、测试、产品文档、GPL、NOTICE 和第三方许可源文件。
- 排除 `.audit`、`.git`、编译输出、缓存、测试结果和常见私钥文件类型。
- 为源码包写入逐文件 SHA-256 清单，并独立回读 ZIP 验证文件集合、路径与内容。
- 通过同卷暂存和目录切换把源码包加入默认交付。
- 修正当前状态文档中仍称“本地预览/尚无正式包”的过时描述。

## 不做什么

不修改运行代码；不重新构建或安装二进制；不包含正式签名私钥、密码、项目外身份记录或 `.audit`；不上传到任何外部位置。

## 涉及文件

- `scripts/New-SourceDelivery.ps1`：源码包生成、验证和默认交付更新入口。
- `.audit/delivery/output/PhoneBridge-NG-0.1.0-source.zip`：正式对应源码包。
- 默认 manifest、SHA256SUMS、README 及当前状态文档。
- 本任务记录、验收报告和 `.audit/runs/P1-044` 机器可读证据。

## 实现

- 新增 `scripts/New-SourceDelivery.ps1`，以明确允许目录收集源码，并排除本地审计、版本库元数据、生成输出、缓存、测试结果和私钥文件类型。
- ZIP 使用固定根目录和固定条目时间，内置 `SOURCE-MANIFEST.json`，记录 263 个源文件的路径、长度和 SHA-256。
- 脚本创建后回读全部 264 个 ZIP 条目，验证路径安全、文件集合、长度和内容散列。
- 通过同卷暂存和目录切换，把源码包及更新后的 README、manifest、SHA256SUMS 写入默认交付；失败时恢复旧目录。
- 更新 Android、Windows、产品、安全、依赖和交付文档中已过时的“本地预览/尚无正式包”描述。

# P2-009 — v0.2.1 挂载状态一致性

状态：实现完成，自动验证通过。日期：2026-09-28。

## 目标

让 Windows 设备卡片、底部状态和资源管理器中的盘符都以实际挂载生命周期为准；手机停止共享或设备离线后尽快确认、安全卸载并刷新资源管理器显示。

## 已实现

- 底部盘符状态改为汇总全部设备会话，按停止失败、缓存恢复、安全卸载、启动、已挂载和无挂载显示，不依赖当前选中项。
- 已配对候选统一使用 `device_id` 作为稳定 UI 身份，候选广播移除后仍能恢复同一选中设备。
- 精确候选消失会立即安排严格会话检查；此提示下两次暂时性失败才确认断连，普通网络错误仍保持三次门槛。
- `share-not-ready` 作为共享已停止的明确结果进入安全卸载，并保留同身份、原盘符的进程内恢复意图。
- 健康检查成功后只显示当前“已连接”，不再留下“手机会话正常”的历史消息。
- 挂载管理器确认盘符缺席后向 Windows Shell 发送驱动器移除通知；卸载失败后的重试会保留待通知状态。待上传或盘符移除未确认时仍保留进程、缓存和所有权。
- Windows 桌面版本已升为 `0.2.1`，三份语言资源一致。

## 未改变

- Android、配对协议、TLS 身份、访问模式和写缓存安全边界未改变。
- 设备备注、自动盘符和设备级盘符偏好留给 P2-010 / v0.2.2。

# P2-025 — v0.2.5 应用内更新验收

状态：已完成；双端更新成功，发现 Android 下载进度反馈缺口。日期：2026-09-30。

## 目标

使用公开正式 `v0.2.4` Windows 与 Android 客户端，通过各自内置“检查更新”发现、下载并交由系统安装正式 `v0.2.5`，验证真实 Release 出现后的完整更新路径。

## 范围

- 实时确认 GitHub Latest 为正式 `v0.2.5`，标签、六项资产和摘要与 P2-024 记录一致。
- 在不清除配对与设置的前提下，把当前双端 v0.2.5 恢复为同签名正式 v0.2.4 基线。
- 分别由用户在 Windows 和 Android 界面触发检查、下载及安装确认，回读版本、进程和保留状态。
- 记录任何系统授权、下载校验、安装器启动或失败关闭行为。

## 不做什么

- 不卸载 Android 应用、不清除应用数据来绕过系统降级限制。
- 不修改 Release、不替换资产、不伪造更高版本或更新响应。
- 不开发代码；若真实流程暴露缺陷，先保留证据并另立修复任务。
- 不推送、不打标签、不创建新 Release。

## 涉及文件

- 本任务记录。
- GitHub Release `v0.2.4` 与 `v0.2.5` 的既有公开资产。

## 实现

不修改产品代码。

## 测试

- Windows：从正式 v0.2.5 静止状态使用正式 v0.2.4 安装器恢复基线，安装退出码 0；配对文件 SHA-256 前后均为 `FE363A3DE97ABBA9303D1E66FFD35C2FD8348CBBF5FDA7F6F25C7B5236FC547B`，无 rclone、无 E:、客户端未自动启动。
- Windows v0.2.4 实际点击“检查更新”后日志依次记录 `Checking`、`Success/Available`；用户确认下载后记录 `Success/Downloaded`。下载文件为 `PhoneBridge-NG-Setup-0.2.5.exe`，大小 81177962 字节，SHA-256 `2A1209B9935BE2EA6A3DD3AC083A98F48E119801D99FCD616F5375BDA455DB2E`，与 GitHub Release 一致。
- 用户确认立即安装后，日志记录 `Starting`、`AppStopping`、`Success/Starting`；安装向导完成时已安装文件/产品版本为 `0.2.5.0` / `0.2.5`，配对散列不变。点击“完成”后客户端自动启动，安装器进程归零，窗口显示“当前版本：0.2.5”、原配对设备、安全模式和上次连接 IP；无 rclone、无 E:。
- 更新后再次点击“检查更新”，用户确认提示“当前已是最新版”；日志记录 `Checking`、`Success/Healthy`。
- Android：当前正式 v0.2.5/versionCode 7 已退出且无 8273。使用同签名正式 v0.2.4/versionCode 6 执行保留数据降级时，Android 返回 `INSTALL_FAILED_VERSION_DOWNGRADE`；应用仍保持 v0.2.5，未卸载、未清除数据。
- 经用户明确授权接受清除配对与应用设置后，卸载 v0.2.5 并全新安装正式 v0.2.4/versionCode 6；安装后未运行、未共享、无 TCP 8273。用户在设置页实际点击“检查更新”，界面显示“发现新版本 0.2.5”，UI hierarchy 同时回读当前版本 0.2.4、目标版本 0.2.5 以及“下载”按钮。
- 用户确认下载和系统安装后，包管理器回读 versionName 0.2.5、versionCode 7，firstInstallTime 保持 `2026-09-29 06:47:19`，lastUpdateTime 更新为 `2026-09-29 18:14:30`；Android 应用内更新成功。
- 真实下载期间没有弹窗、进度条或百分比反馈。源码核对确认 `downloadUpdate` 只在下载开始前调用一次静态 `update_downloading` 文案，而 `AndroidUpdateService.download` 没有进度回调；该体验缺口进入后续独立修复任务，不把更新成功误报为失败。

## 验收结果

通过。Windows 真实正式 Release 的发现、下载、摘要校验、安装确认、安全退出、安装器启动、覆盖安装、自动重启、配对保持及更新后“当前已是最新版”均已回读。Android 在用户授权清除应用数据后从正式 v0.2.4 全新基线完成内置检查、下载和系统覆盖安装，包管理器确认 v0.2.5/versionCode 7 且 firstInstallTime 保持。

验收同时发现 Android 下载期间缺少持续可见的进度反馈。更新本身成功；该 UI 缺口不在本任务内修改，进入下一独立任务。

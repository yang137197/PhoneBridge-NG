# P2-006 — UI、多会话接线与完整语言收口

状态：已完成。日期：2026-09-26。

## 目标

按已确认的 v0.2 设计收口 Windows 与 Android 可见 UI，使简体中文/English 在当前界面、托盘、对话框、通知和错误文本中使用同一持久选择；Windows 多设备卡片的处理与取消状态只作用于对应设备。

## 已实现

- Windows 默认简体中文，语言选择按正式/候选数据根隔离并持久化；动态资源绑定立即刷新当前窗口，托盘同步刷新，代码生成的状态文本保留资源键后重绘。
- Windows 设备卡片按本设备会话显示忙碌、禁用和取消状态，不把单设备操作扩成全局忙状态。
- Android 后台服务和通知使用与页面一致的 `AppLanguage` Context；应用内切换会刷新运行中的前台通知。
- 三份 Windows 资源和两份 Android 资源键保持一致；新增语言存储、动态刷新和单卡状态针对性测试。
